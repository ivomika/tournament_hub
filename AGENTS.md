# Инструкции для работы с TournamentHUB

Перед любой работой в репозитории обязательно прочитай документы в таком порядке:

1. [ai-context/README.md](ai-context/README.md).
2. [ai-context/rules/README.md](ai-context/rules/README.md).
3. Все обязательные правила, перечисленные в router.
4. [ai-context/task-list.md](ai-context/task-list.md) и связанную карточку задачи, если она есть.
5. Conditional rules, чей trigger соответствует scope задачи.

Любое изменение репозитория выполняется через задачу в едином `task-list.md`. До первого изменения переведи её в `🚧 В работе`; после завершения честно заполни критерии, проверки, ключевые решения и итог, затем поставь `✅`.

Правки и уточнения в пределах цели продолжают исходную задачу без нового номера: при необходимости создай для существующего номера detail, переоткрой задачу, добавь в append-only `Changelog` дословный prompt пользователя, изменения и проверки, затем закрой повторно. Новая независимо принимаемая цель получает отдельную задачу.

`AGENTS.md` не дублирует правила: канонический текст находится в `ai-context`. Прямые требования пользователя имеют приоритет над этими инструкциями.
