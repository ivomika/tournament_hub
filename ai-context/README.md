# AI Context

`ai-context` — постоянная рабочая память проекта для задач, выполняемых AI-агентами и командой. Она позволяет восстановить контекст, ограничения и принятые решения между отдельными сессиями.

## Состав

- `task-list.md` — краткий реестр всех задач и их актуальных статусов.
- `tasks/` — детальные карточки задач.
- `templates/task.md` — обязательный шаблон новой карточки.

## Назначение

Карточка задачи отвечает на вопрос «что и почему сейчас делаем». Архитектурная документация и ADR отвечают на вопрос «как устроена система и почему она устроена именно так». Итоговые архитектурные решения нельзя оставлять только в карточке задачи: их необходимо переносить в `docs`.

В `ai-context` запрещено сохранять пароли, токены, персональные данные и другие секреты.

## Декомпозиция через `$task`

Локальный skill `$task` анализирует запрос пользователя и оформляет его как одну или несколько детальных задач:

```text
$task Добавить создание турнира, проверку состава и сохранение черновика
```

Skill изменяет только `task-list.md` и карточки в `tasks/`. Он не реализует созданные задачи, не изменяет приложение и останавливается после записи декомпозиции. Реализация начинается отдельным запросом.
