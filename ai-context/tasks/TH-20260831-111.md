# TH-20260831-111: Исправить пустой Spectator Web при packaged bundle

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: браузер получил `index.html` вместо JS asset.

## Цель

Гарантировать, что packaged Spectator bundle из macOS sandbox раздаётся по тем же абсолютным `/assets` и `/fighters` путям, а SPA fallback не подменяет отсутствующие статические ресурсы `index.html`.

## Scope

- Входит: static bundle resolution/restart и strict fallback для asset paths; HTTP regression test; runtime smoke check.
- Не входит: изменение React UI, WebSocket protocol, QR, domain semantics или renderer macOS.

## Routing и evidence

- Router: [`ai-context/rules/README.md`](../rules/README.md), routing `2026-08-31`.
- Core: 00 workflow — карточка до изменений; 01 authority — Operations/ADR-0012; 08 quality — HTTP/browser smoke; 10 scope — только static serving; 11 safety — без commit без запроса.
- Conditional: 02 Architecture (infrastructure adapter), 05 Network/security (LAN HTTP/static exposure), 09 Docs/assets (operations behavior). 06/07 не применяются: UI не меняется.

## Plan

1. Запретить SPA fallback для `/assets/*`, `/fighters/*` и прочих static resources.
2. Добавить regression test на content type/body для JS и CSS и fallback для document routes.
3. Перезапустить packaged Host и проверить root/asset HTTP responses.

## Criteria

- [x] `/assets/*.js` возвращает JavaScript, а не HTML.
- [x] `/assets/*.css` возвращает CSS, а не HTML.
- [x] `/spectator` и другие document routes получают SPA index.
- [x] Runtime packaged bundle определяется после перезапуска приложения.

## Checks

- Spectator LAN server HTTP tests.
- macOS packaged smoke/build и `flutter analyze`, `make architecture`, `git diff --check`.

Фактически выполнено:

- `flutter test test/infrastructure/spectator/spectator_lan_server_test.dart` — 7 тестов пройдено; проверены existing/missing JS, MIME и SPA fallback.
- `flutter analyze` — без замечаний.
- `make architecture` — layer import и design-system checks пройдены.
- `flutter build macos --debug` — успешно; `.app` содержит `assets/spectator/index.html` и актуальные hashed JS/CSS assets.
- `git diff --check` — пройдено.
- После перезапуска старый Host-процесс, работавший из sandbox cwd, больше не используется; новый packaged bundle разрешает absolute `/assets/*` пути.

## Результат

Пустой Spectator был вызван не React-рендером: старый запущенный Host из sandbox не имел актуального bundle, а универсальный SPA fallback возвращал `index.html` на запрос JS asset. Браузер получал `text/html` вместо JavaScript и оставлял `#root` пустым. Теперь bundle синхронизируется и пакуется в macOS app, runtime использует packaged assets, а fallback применяется только к document routes; отсутствующие ресурсы возвращают 404 вместо HTML.
