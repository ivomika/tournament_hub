# TH-20260825-016: Сделать `make run` кроссплатформенным

- Статус: Выполнена
- Создана: 2026-08-25
- Обновлена: 2026-08-25
- Источник: запрос пользователя запустить `make run` на Windows.

## Цель

Одна команда `make run` собирает и встраивает Spectator Web, затем запускает Flutter Host на desktop-устройстве текущей ОС как на Unix-системах, так и на Windows.

## Контекст

Текущий Makefile принудительно использует `/bin/sh`, по умолчанию выбирает устройство `macos`, а копирование spectator bundle выполняет Unix-командами `mkdir -p` и `cp -R`. Эти предположения делают `make run` неработоспособным в обычном Windows-окружении. Семантика команды — production-сборка spectator, копирование bundle и запуск Host — должна сохраниться.

## Границы задачи

### Входит

- Удаление принудительной зависимости Makefile от `/bin/sh`.
- Автоматический выбор `windows`, `macos` или `linux` как Flutter device с сохранением `FLUTTER_DEVICE` override.
- Кроссплатформенное копирование spectator bundle средствами Dart.
- Документация запуска на Windows и Unix.

### Не входит

- Установка GNU Make, Flutter, Node.js или desktop toolchain.
- Изменение production-сборки spectator либо Flutter-приложения.
- Фактический запуск build/run в рамках проверки: пользователь отдельно запретил запускать билды.

## Требования и ограничения

- `make run FLUTTER_DEVICE=<id>` продолжает явно выбирать устройство.
- Скрипт копирования не использует shell-specific команды.
- Ошибка отсутствующего `dist` завершается ненулевым кодом и понятным русским сообщением.
- Билды и приложение при реализации не запускаются.

## План

1. Сделать определение desktop-device и shell Makefile кроссплатформенными.
2. Добавить Dart-скрипт копирования spectator bundle и подключить его к target.
3. Обновить корневой README примерами Windows и override устройства.
4. Проверить форматирование/анализ скрипта и dry-run Make при доступности команды.

## Критерии приёмки

- [x] `make run` не содержит обязательных Unix-only shell операций.
- [x] На Windows выбирается Flutter device `windows`, на macOS/Linux — соответствующий desktop device.
- [x] `FLUTTER_DEVICE` переопределяет автоматический выбор.
- [x] Bundle копируется кроссплатформенным скриптом.
- [x] README и проверки без запуска build актуальны.

- `make -n run` и `make -n run FLUTTER_DEVICE=<id>`, если GNU Make доступен.

`make run` теперь использует `windows` на Windows, `macos` на macOS и `linux` на остальных Unix-системах; явный `FLUTTER_DEVICE` имеет приоритет. `bundle-spectator` копирует `dist` через `tools/scripts/bundle_spectator.dart`, поэтому не требует Unix-команд. Корневой README и справка scripts описывают Windows prerequisites и примеры. Production build намеренно не запускался.
