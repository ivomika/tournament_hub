# TH-20260830-098: Зафиксировать Spectator projection и read-only protocol contract

- Статус: Выполнена
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P9/P10 scope для обязательного Spectator при исключённом Participant.

## Цель

Определить versioned public DTO/events для Spectator, которые Host публикует без mutation surface и без Participant-specific state/connect semantics.

## Контекст

Data docs задают envelope, sequence/revision и role projections. OD-003 остаётся Participant-blocker; в этой задаче закрываются только Spectator subsets OD-012/014. Spectator должен видеть tournament summary, assignments, matches, bracket/standings, results и champion.

## Границы задачи

### Входит

- Spectator-only HTTP bootstrap/full snapshot и WebSocket event schemas.
- Public projection/redaction, sequence/replay/stale behavior, limits and compatibility.
- JSON fixtures, schema validation и contract/security tests.

### Не входит

- Participant handshake/join/QR/cache/reconnect/notifications.
- Host server implementation (099) и React UI (100).

## Требования и ограничения

- Spectator read-only; client command endpoint отсутствует.
- Projection исключает profile IDs, local history/settings, addresses и diagnostics.
- Host authority, revision/sequence, full snapshot fallback и event ordering обязательны.

## Журнал решений

- 2026-08-30 — protocol scope разделён: Spectator read-only projection входит в MVP, Participant handshake/connect откладывается.
- 2026-08-30 — OD-012/014 закрыты только для Spectator: unlimited protocol-level connections, bounded replay/payload и strict public allowlist; Participant subsets остаются вне MVP.
- 2026-08-30 — V1 event заменяет public projection целиком; client не вычисляет progression и при gap требует replay/snapshot.

## Результат

Зафиксирован Spectator-only protocol v1: strict handshake без business request surface, replace-only public event, sequence/replay/full-snapshot правила, bounded payload/replay и unlimited protocol-level connections. Добавлены closed JSON Schema, synthetic handshake/snapshot/event fixture и contract/security tests. Public allowlist исключает profile/local/network/diagnostic поля; Participant wire contract не реализован.

Серьёзные решения оформлены как [SPEC-001/SPEC-002](../../docs/data/websocket-protocol-v1.md#решения-spec-001--spec-002) и закрывают Spectator subsets OD-012/OD-014.
