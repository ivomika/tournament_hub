# TH-20260830-098: Зафиксировать Spectator projection и read-only protocol contract

- Статус: Готова
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P9/P10 scope для обязательного Spectator при исключённом Participant.

## Цель

Определить versioned public DTO/events для Spectator, которые Host публикует без mutation surface и без Participant-specific state/connect semantics.

## Контекст

Data docs задают envelope, sequence/revision и role projections, но OD-003/012/014 требуют уточнения. Spectator должен видеть tournament summary, assignments, matches, bracket/standings, results и champion.

## Границы задачи

### Входит

- Spectator-only HTTP bootstrap/full snapshot и WebSocket event schemas.
- Public projection/redaction, sequence/replay/stale behavior, limits and compatibility.
- JSON fixtures, schema validation и contract/security tests.

### Не входит

- Participant handshake/join/QR/cache/reconnect/notifications.
- Host server implementation (099) и React UI (100).

## Требования и ограничения

- Spectator read-only; client command endpoint отсутствует.
- Projection исключает profile IDs, local history/settings, addresses и diagnostics.
- Host authority, revision/sequence, full snapshot fallback и event ordering обязательны.
