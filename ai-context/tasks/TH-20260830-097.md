# TH-20260830-097: Реализовать immutable history и Host statistics

- Статус: Выполнена
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P8 implementation plan и MVP outcome.

## Цель

Показать Finished/Cancelled snapshots, полную ranking/structure и derived profile statistics с корректным исключением technical results из normal Match Win Rate.

## Контекст

Persistence contract и Host terminal flow завершены в 093/096; history не должна читать mutable active state или current roster references.

## Границы задачи

### Входит

- History list/detail, read-only tournament summary, champion/ranking/rounds.
- Derived counts/wins/win rate/best place/recent tournaments.
- Clear history confirmation и snapshot isolation/replay.

### Не входит

- Participant history/cache или spectator history API.
- Изменение Domain scoring/ranking rules.

## Требования и ограничения

- Только Finished/Cancelled; snapshots self-contained и immutable.
- Technical results не входят normal Match Win Rate; cancelled не получает champion.
- Clear history — explicit atomic transaction, individual delete отсутствует.

## Журнал решений

- 2026-08-30 — history task не изменяет ranking semantics; потребляет versioned engine outcome.
- 2026-08-30 — derived statistics contract зафиксирован как STAT-001 в Product canon; persisted schema/cache authority не меняются, поэтому ADR не требуется.
- 2026-08-30 — Cancelled projection всегда скрывает engine outcome/ranking, даже если engine успел стать complete до команды отмены.

## Результат

Реализован History application read model поверх immutable versioned snapshots: Finished/Cancelled list/detail, self-contained participant/fighter identities, полная ranking/structure Finished и только фактические данные Cancelled. Profile получает пересчитываемые tournament/match win rates и best place; technical results исключены из normal Match Win Rate. Clear history выполняется существующей atomic transaction после отдельного confirmation и не затрагивает active tournament.

Серьёзное решение связано с [STAT-001](../../docs/product/README.md#решение-stat-001); UI потребляет только готовые application projections.
