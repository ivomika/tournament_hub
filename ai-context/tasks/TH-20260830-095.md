# TH-20260830-095: Реализовать versioned DE/SE/RR engines, scoring и tie-break

- Статус: Черновик
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P6 implementation plan и tournament rules.

## Цель

Создать registry versioned engines для Double Elimination, Single Elimination и Round Robin: schedule, rounds/bouts, normal/technical result, correction boundary, ranking и champion.

## Контекст

Domain rules описывают invariants, RR points и mini-RR tie-break, но OD-005–008 оставляют незакрытыми FT, bouts storage, placement tie policy и RR termination safety. До решения 090 задача не готова.

## Границы задачи

### Входит

- Independent DE/SE/RR engines и conformance suite.
- Match-level result selection, score calculation, technical/forfeit/withdrawal.
- Round matrix per battle, RR pair schedule, mini-RR tie-break records, champion/ranking.
- Correction invalidation only before dependent Finished match.

### Не входит

- UI business logic, persistence adapters, Participant states/connect.
- Guessing unresolved OD values.

## Требования и ограничения

- Engine owns Current queue, stable match IDs, no self-match, bye semantics and completion readiness.
- RR main points: 2:0→3/0, 2:1→2/1, technical→3/0; tie-break does not mutate main points.
- Draws запрещены; Finished/Cancelled immutable.
