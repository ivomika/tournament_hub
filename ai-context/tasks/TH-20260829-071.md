# TH-20260829-071: Пересобрать desktop-размещение действий и иерархию заголовка

- Статус: Выполнена
- Создана: 2026-08-29
- Обновлена: 2026-08-29
- Источник: P1-вывод аудита о вертикальном trailing stack, который визуально не связан с PageHeader

## Цель

Сделать desktop actions частью контекста экрана: primary выровнено с заголовком и контекстом, вторичные действия доступны через overflow, а destructive actions отделены.

## Контекст

На desktop текущие действия отображаются вертикально рядом с header и выглядят центрированными относительно всего layout, а не относительно смыслового заголовка. Аудит запретил bottom fixed dock для desktop.

## Границы задачи

### Входит

- Пересборка desktop placement в `PageHeader`/toolbar boundary по контракту 069.
- Правила для одного, двух и более действий; overflow при количестве больше двух.
- Выравнивание title, subtitle, status и primary action.
- Адаптация для широкого и промежуточного desktop/tablet класса.

### Не входит

- Mobile ActionDock и его inset-логика (069–070).
- Изменение domain permissions и маршрутов.
- Новый визуальный стиль шрифта или redesign всех компонентов.

## Требования и ограничения

- Не использовать высокий вертикальный action stack и desktop bottom fixed bar.
- Primary не теряется среди status/metadata; destructive action визуально и семантически отделена.
- Вся композиция строится через публичный design-system API.
