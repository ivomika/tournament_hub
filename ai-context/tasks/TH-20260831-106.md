# TH-20260831-106: Поднять действие Spectator к сообщению о зрительском экране

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: пользовательский аудит Host Open.

## Цель

Сделать переход к подключению Spectator заметным и непосредственно связанным с сообщением о зрительском экране.

## Контекст

Сообщение уже объясняет Spectator, но действие находится далеко от него и теряется в композиции Open.

## Границы задачи

### Входит

- Сгруппировать explanatory copy и primary Spectator action.
- Сохранить понятные loading/unavailable/error states.
- Адаптировать CTA на mobile/desktop и keyboard navigation.

### Не входит

- Изменение LAN server lifecycle, WebSocket protocol или QR payload.
- Переработка всех действий Host вне Open.

## Требования и ограничения

- CTA ведёт в существующий logical Spectator access flow.
- Действие не должно блокировать tournament progression.
- Host сохраняет authority.
