# TH-20260829-055: Пересобрать AppShell, PageHeader и active navigation

- Статус: Выполнена
- Создана: 2026-08-29
- Обновлена: 2026-08-29
- Источник: аудит Widgetbook; общий вывод трёх ролей ревью

## Цель

Сделать shell адаптивным каркасом, где header и content имеют независимые ограничения, а текущий раздел навигации отражает реальный экран.

## Границы задачи

### Входит

- Новый публичный `PageHeader` с вариантами compact/standard/hero и trailing context/action.
- `PageFrame`/`AppShell` с top-aligned content, отдельными max-width для header/content и `activeDestination`.
- Корректный selected state NavigationRail/NavigationBar.

### Не входит

- Изменение маршрутов, domain, persistence, transport или экранного контента.
- Перестройка canonical bracket.

## Требования и ограничения

- Mobile-first, desktop не является растянутой мобильной колонкой.
- Один page heading и один supporting context; accent marker не заменяет иерархию.
- До реализации архитектурное решение оформить в ADR, если появится новый boundary.

## Журнал решений

- 2026-08-29 — shell/header выделены отдельной задачей, потому что одна ошибка каркаса масштабируется на все экраны.
- 2026-08-29 — существующая граница `presentation/design_system` сохраняется: новый ADR не требуется. `PageHeader` становится отдельным DS component, а `AppShell` получает typed active destination без изменения router/navigation authority.

## Результат

Добавлен публичный `PageHeader` с compact/standard/hero вариантами и trailing context. `AppShell` теперь разделяет header и ограниченный content, выравнивает desktop-контент сверху и принимает типизированный `AppDestination`; профиль, история и настройки явно выбирают свой navigation destination. Новый API покрыт Widgetbook use case, navigation test и обновлённой golden matrix. Существующая граница design system не изменилась, поэтому ADR не потребовался.

Итоговый routing повторно сверен с diff: изменения ограничены presentation design system, четырьмя destination call sites, Widgetbook и visual tests; domain, persistence, transport и routes не затронуты.
