# TH-20260830-089: Защитить app lifecycle и state-driven routing contract тестами

- Статус: Готова
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: regression protection для `TH-20260830-086`–`TH-20260830-088`

## Цель

Ввести автоматические contract, architecture и integration tests, которые блокируют возврат к router-owned lifecycle, прямым navigation mutations и невалидным bootstrap transitions.

## Контекст

ADR и реализация могут быть обойдены новым экраном, controller или callback. Одного import gate недостаточно: он не доказывает, что router не вызывает команды и что bootstrap действительно публикует состояние после restore/commit.

## Границы задачи

### Входит

- Unit/property tests app lifecycle state machine и bootstrap guards.
- Contract tests для read-only AppState publisher, ordering, restart/recovery и disposal.
- Router projection/guard tests и negative no-side-effect tests.
- Architecture fitness check для запрещённых app/router imports и command calls, если это необходимо для machine enforcement.
- Интеграция tests/gates в `make architecture`, `make test` или `make check` без broad ignore.
- Обновление testing/architecture documentation фактическими командами и coverage contract.

### Не входит

- Новая production behavior сверх 087–088.
- Полный E2E на устройствах, LAN networking и spectator.
- Tournament engine/property suites и persistence schema migration.
- Изменение ADR-0011 без отдельного решения 086.

## Требования и ограничения

- Tests должны отличать AppState publication от route selection.
- Negative cases обязаны падать при router→lifecycle mutation и bootstrap→router coupling.
- Проверяется каждое state transition guard, включая missing profile, active restore, recoverable/fatal и terminal/read-only.
- Fakes deterministic; timestamps/IDs не делают тесты flaky.
- Gate не разрешает suppression, broad allowlist или отключение assertions.
- Проверки запускаются локально стандартным `make` интерфейсом.
