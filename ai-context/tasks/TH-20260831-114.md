# TH-20260831-114: Пересобрать Host Distribution в grid назначенных игроков

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: запрос пользователя; текущий `wrap` визуально распадается и плохо управляется.

## Цель

Показывать назначенных игроков Host Distribution в устойчивом grid с предсказуемым порядком, читаемыми fighter identity и адаптацией под mobile/tablet/desktop без `Wrap`-переносов.

## Контекст

Distribution — рабочий экран управления назначениями. Визуальный grid не должен менять структуру данных или правила reroll; меняется только presentation composition.

## Границы задачи

### Входит

- Grid-композиция карточек назначенных участников.
- Адаптивные width classes, overflow/long nickname и empty/loading/error states.
- Widgetbook/golden coverage и проверка touch/keyboard порядка.

### Не входит

- Domain assignment, random seeding, reroll semantics и roster.
- Изменение общего ActionDock или fighter artwork.

## Требования и ограничения

- После assignment показывать fighter name, artwork, nickname и guest label.
- Карточки не должны перекрываться или терять identity при любом поддерживаемом размере.
- Использовать публичный Design System API; `Wrap` не является layout-моделью этого экрана.

## Результат

Host Distribution использует публичный `ParticipantAssignmentGrid` с собственной typed theme: 1/2/3 колонки выбираются по доступной ширине, строки растут под длинный текст, порядок participants не меняется. Добавлены empty/loading/error presentations, Widgetbook use cases, adaptive/semantics tests и актуальные mobile/desktop goldens. Domain assignment и reroll semantics не изменялись.
