# TH-20260829-076: Устранить перекрытие fixed action stack на mobile

- Статус: Выполнена
- Создана: 2026-08-29
- Обновлена: 2026-08-29
- Источник: golden-аудит — dock может перекрывать нижний critical content на Host Running/Finished и Participant Running

## Цель

Гарантировать, что `ActionDock`, `NavigationBar`, `SafeArea`, keyboard insets и scroll body образуют одну корректную композицию: ни один meaningful/dominant object не перекрывается fixed region.

## Контекст

Golden-проверки фиксируют viewport, но текущий контракт проверяет в основном высоту dock и отсутствие exception. На длинных Host/Participant screens нижняя часть matchup/hero может уходить под fixed stack. Это P0-регрессия, блокирующая дальнейшее расширение visual polish.

## Границы задачи

### Входит

- Расчёт нижнего inset scroll content по фактической высоте dock/navigation/safe-area.
- Проверка short-height, portrait/landscape, keyboard и 200% scale.
- No-overlap assertions для Host и Participant screen compositions.
- Проверка focus/semantics при появлении, исчезновении и loading-состоянии dock.

### Не входит

- Новые actions, routes, domain lifecycle или network behavior.
- Изменение общего action placement contract ADR-0007.
- Runtime typography/font fallback и оценка ширины кириллических glyphs.
- Новые tokens, если существующих значений достаточно.

## Требования и ограничения

- Fixed stack не превышает действующие portrait 25% и landscape 20% ceilings.
- Нижняя граница последнего critical content выше `ActionDock + NavigationBar + SafeArea + viewInsets`.
- Keyboard не закрывает focused field или primary action.
- При исчезновении focused action focus возвращается на ближайший стабильный control.
- Проверяются 320×568, 320×720, 390×844, landscape и 200% text scale.

## Журнал решений

- 2026-08-29 — P0 ограничен геометрией fixed stack и accessibility; typography deferred.
- 2026-08-29 — если dock вместе с global navigation не укладывается в portrait 25% / landscape 20% либо text scale превышает 150%, `AppShell` временно скрывает navigation и сохраняет приоритет critical action.
- 2026-08-29 — при открытой клавиатуре navigation скрывается, а dock поднимается на `viewInsets`; scroll body получает гарантированный нижний зазор.

## Результат

`AppShell` теперь рассчитывает fixed-stack budget из orientation, viewport и text scale, поднимает `ActionDock` над клавиатурой и не держит рядом global navigation, когда композиция перестаёт укладываться в ceiling. Scroll body получил стабильный ключ и дополнительный нижний зазор, поэтому последний critical object можно прокрутить выше dock. Добавлены regression tests короткого viewport, no-overlap после scroll и keyboard behavior; существующие mobile/desktop goldens не изменились. Полный `make check` прошёл.
