# TH-20260829-061: Закрыть accessibility и content/localization gates

- Статус: Выполнена
- Создана: 2026-08-29
- Обновлена: 2026-08-29
- Источник: UX/UI-аудит Widgetbook

## Цель

Провести экранный accessibility/content pass: semantics, focus, contrast, touch targets, длинные русские строки и единый словарь статусов.

## Границы задачи

### Входит

- Semantics для StatusBadge, actions, fighter identity, match states и navigation.
- Keyboard focus/return после dialog/async update; reduced motion и contrast review.
- Замена `Guest` на русское «Гость» и словарь status copy.
- Long text/missing artwork/empty/error matrix.

### Не входит

- Новый feature или изменение domain/protocol.

## Требования и ограничения

- Значение не передаётся только цветом, fighter identity не сокращается до nickname-only.
- Locale strings не собираются так, чтобы ломать переносы.

## Критерии приёмки

- [x] Все interactive elements имеют понятные labels и visible focus.
- [x] Dialog возвращает focus инициатору.
- [x] Русские длинные строки, 200% scale и 320 px не обрезают critical data.
- [x] `Guest` заменён на «Гость» во всех пользовательских местах.
- [x] Contrast/reduced motion/missing artwork проверены.

## Проверка

- `make architecture` — успешно.
- `flutter analyze` — успешно, замечаний нет.
- `flutter test` — успешно, 74 теста.
- Semantics tests проверяют русские status/guest labels, loading action announcement, fighter/standing/link identities и отсутствие English `Guest` в UI.
- Dialog test подтверждает safe autofocus и возврат focus инициатору после закрытия.
- Viewport matrix 320/375/599/768/1024/1280, 200% text scale и отдельный reduced-motion stale state проходят без overflow.
- Contrast test подтверждает WCAG 4.5:1 для primary/secondary text pairs; missing-artwork fallback test остаётся зелёным.
- Golden matrix обновлена для экранов, где виден guest identity; `docs/design/README.md` дополнен accessibility/content contract.

## Журнал решений

- 2026-08-29 — accessibility и content объединены, потому что текст является carrier semantics, а не косметикой.
- 2026-08-29 — задача активирована после 060. Проверка ограничена presentation semantics/focus/content; domain/protocol и token values не меняются.

## Результат

`StatusBadge` получил единый semantics label «Статус: …», `DsAction` — enabled/onTap semantics и focus API, `FighterAvatar` и составная `ParticipantIdentity` исключают дублирующие child announcements. Пользовательский `Guest` заменён на «Гость», включая nickname fixture и badge. Добавлен `showTournamentConfirmationDialog`, который восстанавливает focus инициатору; safe action в confirmation получает autofocus. Accessibility/content contract закреплён в design canon.

Итоговый routing сверен с diff: изменения ограничены presentation semantics/focus/copy, tests, goldens и owning design document. Domain, protocol, routes, token values и assets не менялись; ADR/rule-change entry не требуются.
