# TH-20260829-058: Унифицировать connection, stale и recoverable states

- Статус: Готова
- Создана: 2026-08-29
- Обновлена: 2026-08-29
- Источник: UX/UI и security-аудит participant/spectator states

## Цель

Сделать состояния connected, reconnecting, stale, disconnected, incompatible и retry единым явным контрактом без маскировки last-known data.

## Границы задачи

### Входит

- Typed connection state model на presentation boundary.
- `ConnectionBanner` с timestamp/синхронизацией, recovery CTA и текстовой семантикой.
- Widgetbook stress stories для всех connection states.

### Не входит

- WebSocket protocol, reconnect algorithm, DTO, permissions и redaction.

## Требования и ограничения

- Client не становится authoritative.
- Stale блокирует mutation и явно помечает данные как устаревшие.
- Error copy не показывает stack trace/raw payload.
