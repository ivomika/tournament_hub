# TH-20260831-110: Отключить Impeller на macOS по умолчанию

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: диагностика артефактов и деградации производительности на Intel macOS.

## Цель

Зафиксировать и применить opt-out от Impeller для macOS, сохранив Skia/Metal как renderer по умолчанию приложения до отдельной повторной проверки стабильности.

## Границы

### Входит

- `FLTEnableImpeller=false` в macOS application `Info.plist`.
- ADR и design/development documentation с причиной, областью действия, rollback и проверкой.
- Проверка сборки и renderer log.

### Не входит

- Изменение Flutter SDK, обновление Xcode или GPU-драйверов.
- Оптимизация bracket/layout или переписывание shader/QR renderer.
- Отключение Impeller на iOS/Android/Web.

## План и критерии приёмки

1. Добавить ADR-0013 и ссылку в индекс ADR.
2. Установить `FLTEnableImpeller=false` в macOS Info.plist.
3. Обновить каноническую документацию о macOS renderer.
4. Проверить plist, macOS build и runtime log.

- [x] macOS release/profile/debug по умолчанию не используют Impeller.
- [x] Skia/Metal renderer подтверждён runtime log.
- [x] Документация содержит rationale, последствия и rollback.
- [x] Другие платформы не изменены.

## Проверки

- `plutil` для Info.plist.
- `flutter build macos --debug` и/или profile.
- запуск macOS с verbose log и проверка `Skia rendering backend (Metal)`.
- `flutter analyze`, `make architecture`, `git diff --check`.

Фактически выполнено:

- `plutil -lint macos/Runner/Info.plist` — OK.
- `flutter build macos --debug` — успешно.
- `flutter run -d macos --profile` — runtime подтвердил `Using the Skia rendering backend (Metal)`.
- `make architecture`, `flutter analyze` и `git diff --check` — пройдены.
- A/B исходного запуска зафиксирован ранее: Flutter 3.47 использовал `MetalSDF` (Impeller); после opt-out используется Skia/Metal.

## Результат

Impeller отключён для macOS через `FLTEnableImpeller=false`; решение оформлено в [ADR-0013](../../docs/adr/0013-macos-skia-default-renderer.md). Другие платформы и renderer-поведение не изменялись.
