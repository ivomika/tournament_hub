# TH-20260825-002: Сделать реестр задач человекочитаемым

- Статус: Выполнена
- Создана: 2026-08-25
- Обновлена: 2026-08-25
- Источник: запрос пользователя упростить `task-list`, убрать таблицы, заменить словесные статусы emoji и сохранить ссылки на карточки.

## Цель

`ai-context/task-list.md` читается как компактный плоский список: задачи имеют сквозные номера без привязки к дате и emoji-статусы, а каждая запись сохраняет ссылку на детальную карточку.

## Контекст

Полный ID `TH-ГГГГММДД-NNN` нужен для уникальности карточек и зависимостей, но перегружает краткий реестр. Таблица плохо читается при длинных названиях и на узком экране.

## Границы задачи

### Входит

- Замена таблиц в `task-list.md` на маркированные списки.
- Сквозная нумерация записей без группировки или зависимости от даты.
- Emoji вместо словесного статуса в строке реестра.
- Сохранение ссылок на полные карточки.
- Обновление процессных правил и локального skill `task` под новый формат.

### Не входит

- Переименование существующих карточек и изменение их полных ID.
- Замена словесного статуса внутри детальной карточки.
- Изменение жизненного цикла задач.

## Требования и ограничения

- Полный ID остаётся стабильным в имени файла, заголовке карточки и зависимостях.
- Короткий номер уникален во всём реестре и не вычисляется из полного ID карточки.
- Реестр не использует Markdown-таблицы.
- Значение emoji однозначно описано легендой.

## План

1. Зафиксировать формат строки, сквозную нумерацию и легенду emoji.
2. Перенести существующий реестр в списочный формат.
3. Обновить `ai-context/README.md`, `AGENTS.md` и локальный skill `task`.
4. Проверить ссылки, уникальность сквозных номеров и отсутствие таблиц.

## Критерии приёмки

- [x] В `task-list.md` отсутствуют Markdown-таблицы.
- [x] Все существующие задачи представлены списком и сохраняют рабочие ссылки.
- [x] Номера являются сквозными `NNN` и не привязаны к дате.
- [x] Статусы в реестре показаны только emoji.
- [x] Процессные инструкции описывают новый формат.

## Проверка

- `rg '^\\|' ai-context/task-list.md`: не находит строк таблицы.
- Проверка ссылок из реестра: каждый target существует.
- Проверка сквозных номеров: значения уникальны и идут без пропусков.

## Журнал решений

- 2026-08-25 — полный ID сохраняется как внутренний идентификатор; в реестре показывается только `NNN` внутри секции даты.
- 2026-08-25 — словесный статус остаётся в карточке для машинно-однозначного процесса, а краткий реестр использует emoji.
- 2026-08-25 — по уточнению пользователя группировка по датам удаляется; display number становится отдельным сквозным номером реестра, а существующие полные ID карточек сохраняются ради совместимости ссылок и зависимостей.

## Результат

`task-list.md` переведён с таблиц и группировки по датам на плоские списки. В строке отображаются emoji-статус, отдельный сквозной номер `NNN`, название и ссылка на карточку; полные ID сохранены только в target-файлах и ссылках. Легенда, `ai-context/README.md`, `AGENTS.md` и локальный skill `task` синхронизированы с новым форматом. Автоматическая проверка подтвердила 25 записей, непрерывные уникальные номера `001–025`, существование всех ссылок и соответствие emoji статусам карточек; `git diff --check` прошёл.
