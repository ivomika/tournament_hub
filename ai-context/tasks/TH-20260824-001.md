# TH-20260824-001: Добавить постоянный AI-контекст и процесс работы с задачами

- Статус: Выполнена
- Создана: 2026-08-24
- Обновлена: 2026-08-24
- Источник: запрос пользователя о добавлении `ai-context`, реестра задач, шаблона и обязательной детализации работы.

## Цель

Создать в репозитории постоянную файловую память задач и закрепить обязательный процесс её использования перед изменением приложения.

## Контекст

Архитектура и командные правила уже хранятся в `docs` и `AGENTS.md`, но отсутствует место для сохранения оперативного контекста конкретных задач между AI-сессиями.

## Границы задачи

### Входит

- Создание каталога `ai-context`.
- Создание реестра задач, шаблона и каталога детальных карточек.
- Описание жизненного цикла и статусов задачи.
- Закрепление обязательного процесса в `AGENTS.md`.
- Добавление навигации в корневую документацию.

### Не входит

- Интеграция с внешним task tracker.
- Автоматическая генерация ID скриптом.
- Перенос предыдущих уже завершённых работ в новый реестр.

## Требования и ограничения

- Все записи ведутся на русском языке согласно `AGENTS.md`.
- До реализации задачи должна существовать детальная карточка.
- Реестр остаётся кратким, подробности хранятся в отдельной карточке.
- Секреты и персональные данные в рабочую память не записываются.
- Архитектурные решения дублируются в соответствующей документации или ADR.

## План

1. Создать структуру `ai-context` и шаблон детальной карточки.
2. Добавить реестр и зарегистрировать текущую задачу.
3. Закрепить процесс работы в `AGENTS.md`.
4. Добавить ссылки в корневой README.
5. Проверить ссылки, структуру и полноту правил.
6. Зафиксировать результат и перенести задачу в завершённые.

## Критерии приёмки

- [x] Созданы реестр, шаблон и каталог карточек задач.
- [x] В `AGENTS.md` описан обязательный процесс до, во время и после работы.
- [x] Корневой README содержит ссылку на рабочую память.
- [x] Текущая задача завершена через новый процесс.
- [x] Структура и ссылки проверены.

## Проверка

- `test -f` для реестра, шаблона и карточки: все файлы существуют.
- `rg` по ссылкам и обязательным этапам процесса: ссылки из `README.md` и правила из `AGENTS.md` найдены.
- `find ai-context -maxdepth 3 -type f`: структура содержит README, реестр, шаблон и детальную карточку.

## Журнал решений

- 2026-08-24 — выбран реестр с отдельными карточками, чтобы `task-list.md` оставался читаемым при росте проекта.
- 2026-08-24 — формат ID: `TH-ГГГГММДД-NNN`, где номер последовательно увеличивается в пределах даты.

## Результат

Создана постоянная рабочая память `ai-context` с кратким реестром, отдельными карточками и обязательным шаблоном. В `AGENTS.md` закреплён жизненный цикл задачи до, во время и после реализации, включая детализацию, синхронизацию статусов, журнал решений, проверки и сохранение результата. Корневой README содержит навигацию к реестру и шаблону. Перенос предыдущих работ и автоматическая генерация ID намеренно не выполнялись.
