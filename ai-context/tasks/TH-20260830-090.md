# TH-20260830-090: Зафиксировать MVP scope и Spectator projection contract

- Статус: Выполнена
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: запрос на MVP только для Host, локальных Guests и read-only Spectator.

## Цель

Получить утверждённый MVP contract, в котором Host ведёт локальный турнир с Guests, Spectator получает read-only projection, а Participant states и Participant↔Host connection исключены. Правила DE/SE/RR берутся из Design Doc без переутверждения.

## Контекст

Product guide включает Participant, но пользователь явно исключил его из MVP. Для Spectator нужно формализовать wire envelope, порядок событий/восстановление, лимиты подключений и privacy projection; их нельзя заменять догадками.

## Границы задачи

### Входит

- MVP scope matrix Host/Guest/Spectator/Participant.
- Формализация только Spectator projection/capacity/privacy и Host↔Spectator protocol envelope.
- Обновление product/open-decisions/roadmap канона и ADR при необходимости.

### Не входит

- Реализация кода, UI, БД, LAN-сервера или WebSocket.
- Participant state, join/QR/reconnect/cache/notifications.
- Release legal/platform decisions, если они не нужны для MVP локального запуска.

## Требования и ограничения

- Spectator остаётся read-only и не получает profile IDs, local history, settings или diagnostics.
- Host остаётся единственным authority; Guest не получает network projection identity.
- Правила турнира не изменяются относительно Design Doc; незакрытые Spectator protocol/privacy вопросы блокируют только сетевые карточки.
