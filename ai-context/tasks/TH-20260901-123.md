# TH-20260901-123: Показать очки участников в Host Round Robin

- Статус: Готова
- Создана: 2026-09-01
- Обновлена: 2026-09-01
- Источник: запрос пользователя; в Flutter Host для RR не видны полученные участниками очки.

## Цель

Показать authoritative RR points в Host Running/Finished presentation рядом с полной fighter identity, не рассчитывая scoring в UI.

## Контекст

RoundRobinEngine уже владеет points. Нужно проверить application projection и передать готовые значения в design-system standings component.

## Границы задачи

### Входит

- Audit Domain → application projection → Flutter presentation для RR points.
- Typed optional points/standing view data и UI states Running/Finished, если фактический gap это подтверждает.
- Unit/widget/golden evidence и canonical docs update.

### Не входит

- Изменение RR scoring/tie-break rules, ручное редактирование points и Spectator protocol version.

## Требования и ограничения

- Points рассчитывает только `RoundRobinEngine`.
- UI получает готовое число и явно подписывает его как очки; цвет не является единственным carrier.
- SE/DE presentation не показывает ложные RR points.
- Все новые Flutter visuals реализуются через `presentation/design_system` component/theme.
