# TH-20260825-009: Показывать бойца рядом с каждым участником турнира

- Статус: Выполнена
- Создана: 2026-08-25
- Обновлена: 2026-08-25
- Источник: в истории и на экране победителя рядом с участниками не показаны назначенные бойцы.

## Цель

Во всех турнирных представлениях после назначения бойцов участник отображается вместе со своим бойцом. Исторические экраны используют сохранённый snapshot имени бойца.

## Границы задачи

### Входит

- Итоги и экран победителя Double Elimination.
- Список и детали истории Round Robin и Double Elimination.
- Матчи и переигровки активного Double Elimination, где сейчас выводится только nickname.
- Проверка уже существующих экранов Round Robin.
- Widget и repository regression tests.

### Не входит

- Экраны создания турнира до назначения бойцов.
- Изменение fighter assignment.

## Критерии приёмки

- [x] Победитель и каждое итоговое место содержат nickname и fighter.
- [x] Каждый участник в деталях истории отображается с fighter из snapshot.
- [x] Карточка списка истории показывает fighter чемпиона.
- [x] Активные DE-матчи и переигровки не выводят nickname без fighter.
- [x] `make check` проходит.

## Результат

Итоги Double Elimination показывают fighter чемпиона и fighter каждого места, включая avatar. В активной сетке подписи автоматических проходов, исправления и placement replay содержат nickname и fighter. Детали истории обоих форматов и карточка чемпиона в списке истории используют неизменяемые fighter names из finished snapshot. Правило закреплено в `AGENTS.md` и документации турнира.

`make check` прошёл: Flutter analyze, 127 Flutter tests, форматирование, React lint и tests. APK не собирался.
