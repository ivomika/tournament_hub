# TH-20260824-011: Создать chibi avatars бойцов MK11

- Статус: Выполнена
- Создана: 2026-08-24
- Обновлена: 2026-08-24
- Источник: запрос пользователя сгенерировать chibi avatars для MK11 roster.

## Цель

Каждый боец из подтверждённого registry имеет оптимизированный chibi avatar в едином визуальном стиле и доступен приложению через заменяемый asset resolver.

## Контекст

Набор изображений зависит от точного roster из `TH-20260824-010`. Ручное создание отдельных несогласованных prompts приведёт к разному стилю, поэтому нужен единый art specification и воспроизводимый manifest.

Зависимость: `TH-20260824-010`.

## Границы задачи

### Входит

- Единая visual specification для всего набора.
- Генерация отдельного chibi avatar для каждого бойца через image generation workflow.
- Нормализация размеров, формата, background и naming по стабильному fighter ID.
- Asset manifest и абстрактный resolver `fighter ID -> asset`.
- Добавление Flutter assets и проверка отсутствующих/лишних файлов.
- Визуальная QA согласованности набора.

### Не входит

- Player avatar пользователя.
- Анимация, 3D-модели и полноэкранные иллюстрации.
- Runtime-генерация изображений и загрузка assets из интернета.
- Изменение состава roster.

## Требования и ограничения

- Для создания bitmap assets использовать image generation skill, а не программную отрисовку.
- Файлы именуются по стабильным fighter IDs и поставляются вместе с приложением для offline-сценария.
- Внешний вид персонажей должен оставаться узнаваемым, но весь набор использует одну композицию, масштаб, освещение и фон.
- Assets оптимизируются под mobile без потери качества на desktop.
- Art specification: отдельный PNG 512×512 с прозрачным фоном, chibi 3D-иллюстрация по пояс, фронтальный ракурс, единый мягкий студийный свет, персонаж целиком внутри safe area без текста и watermark.

## План

1. Завершить registry и подтвердить полный список asset IDs.
2. Утвердить art specification на одном пробном avatar.
3. Сгенерировать набор по единому prompt template и проверить узнаваемость.
4. Нормализовать и оптимизировать bitmap assets.
5. Создать manifest/resolver и подключить assets во Flutter.
6. Добавить автоматическую проверку соответствия registry и визуальную QA.

## Критерии приёмки

- [x] Утверждены roster и art specification, задача переведена в `Готова`.
- [x] Для каждого fighter ID существует ровно один avatar.
- [x] Все изображения имеют согласованные format, dimensions, framing и background policy.
- [x] Registry и manifest не содержат отсутствующих или лишних записей.
- [x] Assets работают offline и корректно масштабируются на phone/desktop.
- [x] Набор прошёл визуальную QA.

## Проверка

- Автоматическая проверка manifest против `FighterRegistry`: ожидается полное взаимно-однозначное соответствие.
- Проверка размеров и формата assets: ожидается единая спецификация.
- Визуальная сетка всех avatars на phone и desktop: ожидается единый стиль без обрезки.
- `flutter test` и asset build: ожидается успешное выполнение.

## Журнал решений

- 2026-08-24 — avatars хранятся локально и разрешаются через abstraction, чтобы заменить конкретный набор assets без изменения domain/UI contracts.
- 2026-08-24 — сначала утверждается один reference avatar, затем генерируется весь набор; это снижает риск несогласованного стиля.
- 2026-08-24 — выбран полный roster MK11 Ultimate из `TH-20260824-010`; зафиксирован прозрачный PNG 512×512 и единый chibi 3D art direction, задача переведена через `Готова` в `В работе`.

## Результат

Встроенным image generation workflow создано 37 отдельных chibi avatars. Финальные PNG сохранены в `apps/tournament_app/assets/fighters/`, нормализованы до 512×512 RGBA и проверены контактной сеткой. Добавлены versioned manifest, абстрактный `FighterAvatarResolver`, bundled adapter и тест полного соответствия registry/files/PNG metadata. Prompt template и особенность нейтрального prompt для Joker записаны в `docs/product/mk11-avatar-assets.md`. `make check` завершён успешно 2026-08-24.
