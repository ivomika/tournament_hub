# TH-20260829-077: Ввести семантические desktop layout presets

- Статус: Готова
- Создана: 2026-08-29
- Обновлена: 2026-08-29
- Источник: golden-аудит — desktop получает широкий canvas без рабочей page-level композиции

## Цель

Дать desktop-экранам осмысленную композицию вместо растянутого mobile stack: dominant panel, secondary rail, readable max-width и контекстные связи между блоками.

## Контекст

На `profile`, `history`, `host_distribution` и части Host/Participant экранов свободное пространство не имеет назначения. UI и UX аудиторы независимо предложили семантические presets, а критик подтвердил их при условии, что preset описывает композицию, а не набор локальных magic numbers.

## Границы задачи

### Входит

- Typed page-level presets `focused`, `split`, `workspace`, `archive`, `hero` либо эквивалентный минимальный набор.
- Desktop composition для Host Open/Running/Distribution/Finished как первых consumers.
- Readable max-width, dominant/secondary panel roles и структурное отличие desktop от mobile.
- Adaptive fallback preset для medium/compact widths.
- Widgetbook/golden checks на desktop и compact.

### Не входит

- Изменение action contract, routes, guards, domain/network behavior.
- Заполнение whitespace декоративными карточками.
- Новая навигационная система поверх AppShell NavigationRail.
- Runtime typography/font fallback и кириллический type QA.

## Требования и ограничения

- Preset не содержит lifecycle logic, raw colors или локальных magic dimensions.
- Dominant panel занимает ориентировочно 60–75% рабочей композиции, secondary rail 25–40%, когда split оправдан.
- Пустое пространство >35% допускается только при documented centered/hero/terminal rationale.
- На каждом expanded screen есть структурное отличие от mobile, а не только изменение размера.
- Existing design tokens и public DS API остаются единственными источниками visual values.

- [ ] Desktop workspace использует минимум 55% полезной области либо имеет documented rationale.
- [ ] Mobile composition не деградирует и не получает desktop-only rail.
- [ ] Widgetbook/golden проверяют compact/medium/expanded.
- [ ] `make architecture`, `dart analyze`, `make check` проходят.
