# TH-20260830-100: Подключить Spectator Web к Host projection contract

- Статус: Готова
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P10 Spectator Web flow и утверждённый technology baseline.

## Цель

Подключить готовую визуальную оболочку Spectator Web к реальному Host projection contract: принимать snapshot/events, отображать актуальное состояние и безопасно восстанавливаться после разрыва.

## Контекст

Задача 053 отвечает за visual language и компоновку. Здесь реализуется runtime/client integration поверх DTO и протокола 098–099; React/Vite не содержит tournament engine или Participant flow.

## Границы задачи

### Входит

- Typed TypeScript DTO/client projection, native WebSocket event application и full snapshot fallback.
- Reducer для sequence/replay/stale/incompatible состояний и безопасного восстановления.
- Подключение экранов и компонентов задачи 053 к Summary, матчам, bracket/standings и champion.

### Не входит

- Participant states/connect/notifications.
- Изменение Host server/protocol schema (098–099), business scoring/engine и visual redesign задачи 053.

## Требования и ограничения

- Нет create/edit/result/cancel/command controls; UI остаётся read-only.
- Stale view не выглядит live; reconnect не пересчитывает Domain.
- Character artwork/name/nickname соблюдают shared identity contract.
