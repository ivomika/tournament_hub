# TH-20260830-100: Подключить Spectator Web к Host projection contract

- Статус: Выполнена
- Создана: 2026-08-30
- Обновлена: 2026-08-31
- Источник: P10 Spectator Web flow и утверждённый technology baseline.

## Цель

Подключить готовую визуальную оболочку Spectator Web к реальному Host projection contract: принимать snapshot/events, отображать актуальное состояние и безопасно восстанавливаться после разрыва.

## Контекст

Задача 053 отвечает за visual language и компоновку. Здесь реализуется runtime/client integration поверх DTO и протокола 098–099; React/Vite не содержит tournament engine или Participant flow. Host server завершён commit `14399e9`.

## Границы задачи

### Входит

- Typed TypeScript DTO/client projection, native WebSocket event application и full snapshot fallback.
- Reducer для sequence/replay/stale/incompatible состояний и безопасного восстановления.
- Подключение экранов и компонентов задачи 053 к Summary, матчам, bracket/standings и champion.

### Не входит

- Participant states/connect/notifications.
- Изменение Host server/protocol schema (098–099), business scoring/engine и visual redesign задачи 053.

## Требования и ограничения

- Нет create/edit/result/cancel/command controls; UI остаётся read-only.
- Stale view не выглядит live; reconnect не пересчитывает Domain.
- Character artwork/name/nickname соблюдают shared identity contract.

- Participant client и mobile UI не выполнялись по scope.

## Журнал решений

- 2026-08-30 — Spectator Web реализуется как отдельный read-only consumer, даже при исключённом Participant.
- 2026-08-31 — Внешний payload проходит strict allowlist и reference validation до presentation; UI не использует internal DTO напрямую.
- 2026-08-31 — `make test`/`make check` дополнены Vitest suites, чтобы Web contract не выпадал из общего quality gate.

## Результат

Spectator Web переключён с synthetic fixture на same-origin HTTP snapshot + native WebSocket v1. Реализованы typed validator, replace-only sequence reducer, waiting/reconnect/stale/incompatible/full-snapshot recovery, mapping fighter identity/matches/places/champion и read-only экраны Distribution/Running/Finished. Visual components используют generated tokens; standings больше не выдумывает отсутствующие в contract очки/победы.
