# TH-20260831-109: Восстановить Draft, Open и доступность Spectator

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: пользовательская проверка задач 104–107.

## Цель

Исправить регрессию без нового редизайна: сохранить ранее согласованные общие layout Draft и Open, добавить в Draft только редактирование названия и компактный dropdown режима, а Spectator снова сделать доступным по показываемой прямой LAN-ссылке.

## Контекст

В задачах 104–107 точечные product changes были реализованы вместе с лишней перекомпоновкой экранов. Пользователь явно потребовал вернуть общий визуальный каркас, ограничившись перестановкой блоков Open и dropdown в Draft. Текущая Spectator capability скрывает ссылку при `STATIC_BUNDLE_MISSING`, из-за чего доступ к экрану полностью пропадает вместо понятного рабочего или recoverable состояния.

## Границы задачи

### Входит

- Возврат Draft к прежней линейной композиции и визуальной иерархии.
- Поле названия и один dropdown DE/SE/RR внутри прежнего блока параметров.
- Возврат Open к прежнему общему `PageLayout`; перестановка guest form и скрытого Participant invite без полной смены структуры.
- Диагностика и исправление фактической LAN-доступности Spectator, прямой HTTP URI и copy action.
- Регрессионные widget, server и integration tests.

### Не входит

- Новый visual language, токены или редизайн остальных экранов.
- Реализация Participant networking и показ Participant QR.
- Изменение WebSocket protocol, Spectator projection или tournament domain semantics.

## Требования и ограничения

- Сохраняется ранее согласованный visual language и общий layout экранов.
- Participant invite остаётся скрытым, пока capability не реализована.
- Spectator endpoint публичен внутри LAN без защиты согласно текущему MVP contract.
- Недоступность bundle не должна молча превращать рабочий LAN endpoint в отсутствие адреса; состояние должно быть проверяемым и recoverable.

## Журнал решений

- 2026-08-31 — задача корректирующая: не вводит новый дизайн, а возвращает согласованный каркас и сужает изменения до требуемых контролов/перестановки.
- 2026-08-31 — Spectator URI выбирается с физического Wi-Fi/Ethernet раньше VPN/bridge; это operational hardening существующего OD-013, не новый protocol или authority decision.
- 2026-08-31 — generated Spectator Web bundle в Git не хранится: `make run`/`make build` собирают и синхронизируют его во Flutter assets, runtime извлекает packaged assets в cache при отсутствии repository `dist`.

## Результат

Draft возвращён к прежней линейной композиции: внутрь блока параметров точечно добавлены поле названия и один `DsSelect` режима. Open снова построен как прежний общий двухрегионный layout с roster в primary и guest form перед optional Participant invite в secondary; Participant QR остаётся скрытым без capability. Spectator снова публикует и копирует прямой URL, раздаёт root/SPA из подготовленного или packaged bundle, выбирает достижимый LAN interface и имеет необходимые platform permissions.
