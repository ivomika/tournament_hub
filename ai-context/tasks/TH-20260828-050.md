# TH-20260828-050: Выравнять shell, Main и profile screens по новому visual language

- Статус: Черновик
- Создана: 2026-08-28
- Обновлена: 2026-08-28
- Источник: продолжение задачи 049 по запросу пользователя; запускать после подтверждения результата 049

## Цель

Привести `Bootstrap`, `Registration`, `Main`, `Profile` и `Settings` к утверждённому visual language задачи 049, сохранив ясный первый запуск, dominant action и адаптивную mobile/desktop-композицию.

## Контекст

Задача зависит от принятия базового visual direction и shell из [049](TH-20260828-049.md). Эти экраны задают первое впечатление и повторяющиеся паттерны навигации, summary, profile identity и destructive settings.

## Границы задачи

### Входит

- Пересборка app shell, header/navigation, page rhythm и background layers.
- Main с active tournament/next action, empty state и history entry point.
- Registration/Profile с nickname, local identity и fighter artwork там, где participant context уже назначен.
- Settings с понятными destructive confirmations, focus и keyboard order.
- Адаптация compact/medium/expanded и Widgetbook states.

### Не входит

- Изменение profile domain, persistence, routes/guards и tournament lifecycle.
- Изменение token semantics без отдельного ADR.

## Требования и ограничения

- Предшественник: 049; начинать только после её visual review.
- Соблюдать [Design system](../../docs/design/README.md), [Screen map](../../docs/product/screen-map.md) и публичные DS boundaries.
- Полная accessibility/state matrix обязательна для изменённых экранов.

## Критерии приёмки

- [ ] Shell и Main визуально используют baseline 049.

- [ ] Screens проверены на compact/medium/expanded, длинные русские строки и 200% text scale.
- [ ] Screenshot/golden evidence и фактический rule evidence заполнены.
