# TH-20260830-101: Провести MVP Host+Guests+Spectator integration и hardening

- Статус: Заблокирована
- Создана: 2026-08-30
- Обновлена: 2026-08-31
- Источник: P12 hardening и пользовательский MVP scope.

## Цель

Подтвердить полный MVP без Participant: offline Host с локальными Guests проходит все форматы и terminal outcomes, а Spectator получает безопасную read-only projection end-to-end.

## Контекст

Отдельные unit/contract/widget suites не доказывают вертикальную связность Domain→storage→Host→Spectator и restart/publish failure behavior.

## Границы задачи

### Входит

- Host offline E2E Draft→Finished/Cancelled для DE/SE/RR.
- Asset/token/schema/architecture/import gates, restart/terminal transaction tests.
- Host server + browser Spectator integration, stale/reconnect/full snapshot, redaction/security checks.
- MVP known limitations и evidence report.

### Не входит

- Participant state/connect/cache/notifications.
- Production signing/legal release matrix beyond documenting blockers.

## Требования и ограничения

- Не запускать build без отдельного разрешения; quality checks reproducible.
- No Internet dependency for Host cycle; Spectator failure не ломает progression.
- Любые open decisions остаются явно listed, не bypassed.
