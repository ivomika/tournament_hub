# TH-20260830-094: Подключить MK11 roster и уникальную выдачу fighters

- Статус: Готова
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P5 implementation plan; assets pipeline task 048.

## Цель

Валидировать 37 fighters из manifest и реализовать deterministic seed-based bijection participant→unique fighter только на Distribution с `Reroll All`.

## Контекст

Runtime assets уже синхронизируются задачей 048, но Domain GameDefinition/assignment policy и snapshot identity ещё не реализованы.

## Границы задачи

### Входит

- Roster manifest importer/GameDefinition, stable fighter IDs и localized names.
- Injected RNG/seed, full assignment, reroll all, back-to-open cleanup.
- Snapshot/history fighter metadata и property tests.

### Не входит

- Individual reroll/exclusions, Participant assignment UI или network projection.
- Format progression engines.

## Требования и ограничения

- Assignment полная bijection; roster capacity ограничивает participants.
- Randomness тестируется seed-based; cryptographic unpredictability не нужна.
- Missing asset даёт placeholder + fighter name, не ломает Domain.
