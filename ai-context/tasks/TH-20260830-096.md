# TH-20260830-096: Подключить Host application flow от Draft до Finished/Cancelled

- Статус: Выполнена
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P7 implementation plan; Host-only vertical slice.

## Цель

Дать Host рабочий end-to-end цикл создания, набора Guests, распределения fighters, проведения матчей, выбора/исправления результата, завершения или отмены турнира.

## Контекст

Presentation screens, DS и state-driven app router уже существуют как foundations, но application commands/controllers пока не связаны с Domain и persistence. Зависимости 091–095 завершены. OD-004 закрывается versioned correction contract до кода.

## Границы задачи

### Входит

- Host use cases/controllers/state projection для Draft/Open/Distribution/Running/Finished/Cancelled.
- Guest roster, Reroll All, rounds/matches, outcome picker, correction/withdrawal actions.
- Main continue, restart recovery и safe destructive confirmations.

### Не входит

- Participant screens/state/connection.
- Spectator transport/UI (098–100), domain engines (095).

## Требования и ограничения

- UI вызывает application commands; lifecycle/navigation не меняются callbacks напрямую.
- Current match и round state engine-authoritative; result correction соблюдает OD-004.
- Host может завершить/отменить только после commit-ready conditions.

## Журнал решений

- 2026-08-30 — Host UI не получает отдельные Participant routes; Guests являются локальным roster source.
- 2026-08-30 — correction не переписывает event log: новая revision хранит corrected snapshot и append-only correction event; Finished downstream блокирует команду.
- 2026-08-30 — OD-004 оформлен в owning Domain/Data docs; отдельный ADR не нужен, потому что границы слоёв и dependency direction не менялись.
- 2026-08-30 — cold-start сначала определяет profile/active projection, затем при необходимости восстанавливает тяжёлый Host context; router запускается с согласованным состоянием.

## Результат

Реализован offline Host vertical slice для DE/SE/RR: versioned snapshot/replay, crash-safe команды и terminal commit, Draft/Open/Distribution/Running/Finished/Cancelled projections, Guest roster, уникальная раздача/reroll, возврат в Open, матчи и фактический FT-счёт, correction/withdrawal, champion/ranking и выход с terminal экранов на Main. Active состояния восстанавливаются после restart; Cancelled сохраняет только факты без выдуманного результата.

Серьёзное correction-решение зафиксировано как [OD-004](../../docs/domain/format-engine-v1.md#решение-od-004) и связано с [atomic Data contract](../../docs/data/README.md#result-correction).
