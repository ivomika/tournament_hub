# TH-20260830-096: Подключить Host application flow от Draft до Finished/Cancelled

- Статус: Черновик
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P7 implementation plan; Host-only vertical slice.

## Цель

Дать Host рабочий end-to-end цикл создания, набора Guests, распределения fighters, проведения матчей, выбора/исправления результата, завершения или отмены турнира.

## Контекст

Presentation screens, DS и state-driven app router уже существуют как foundations, но application commands/controllers пока не связаны с Domain и persistence.

## Границы задачи

### Входит

- Host use cases/controllers/state projection для Draft/Open/Distribution/Running/Finished/Cancelled.
- Guest roster, Reroll All, rounds/matches, outcome picker, correction/withdrawal actions.
- Main continue, restart recovery и safe destructive confirmations.

### Не входит

- Participant screens/state/connection.
- Spectator transport/UI (098–100), domain engines (095).

## Требования и ограничения

- UI вызывает application commands; lifecycle/navigation не меняются callbacks напрямую.
- Current match и round state engine-authoritative; result correction соблюдает OD-004.
- Host может завершить/отменить только после commit-ready conditions.

## Зависимости и документация

Зависит от 091–095; [screen map](../../docs/product/screen-map.md), [lifecycle](../../docs/product/README.md#lifecycle), ADR-0011.

## План

1. Создать application commands/state projections.
2. Подключить controllers к persistence/engines и router.
3. Провести Host flow с restart/error/confirmation paths.

## Критерии приёмки

- [ ] Host проходит Draft→Open→Distribution→Running→Finished offline.
- [ ] Guests добавляются/удаляются по lifecycle guards.
- [ ] Current match, round matrix, score/winner/correction и champion видимы.
- [ ] Cancelled не показывает выдуманные champion/ranking.
- [ ] Restart в каждом active state восстанавливает продолжение.
- [ ] Host widget/controller/integration tests проходят.

## Проверка

- Планируется: application contract, controller/widget, restart and offline E2E tests.
- Participant state/connect тесты исключены.

## Журнал решений

- 2026-08-30 — Host UI не получает отдельные Participant routes; Guests являются локальным roster source.

## Результат

Заполняется после реализации зависимых engines/storage.
