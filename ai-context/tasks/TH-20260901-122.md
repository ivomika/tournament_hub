# TH-20260901-122: Усилить линии Spectator bracket на больших экранах

- Статус: Выполнена
- Создана: 2026-09-01
- Обновлена: 2026-09-01
- Источник: запрос пользователя; connector lines между карточками плохо видны на большом экране.

## Цель

Увеличить визуальную толщину bracket connectors на large/xlarge Spectator viewport, сохранив token-driven styling и более компактную плотность на малых экранах.

## Контекст

Task 121 добавила каноничные branches шириной базового border token. На телевизоре/большом мониторе одна физическая линия теряется на расстоянии.

## Границы задачи

### Входит

- Семантический emphasis border token в общем manifest и обеих generated bindings.
- Responsive connector width для Spectator elimination lanes.
- Token/visual regression checks и обновление design canon.

### Не входит

- Изменение геометрии/логики связей, цвета карточек, zoom или RR presentation.

## Требования и ограничения

- Новый размер задаётся в `docs/design/tokens.json`, не raw CSS.
- Token генерируется для Flutter и Web; Flutter components менять не требуется.
- На compact/medium остаётся базовая толщина, на large/xlarge применяется emphasis.

## Журнал решений

- 2026-09-01 — используется общий `border.widthEmphasis`, чтобы semantic emphasis был доступен обеим presentation platforms.
- 2026-09-01 — manifest additive change: version `1.2.0 → 1.3.0`, schema и существующие paths совместимы.
- 2026-09-01 — large boundary использует каноничный `breakpoint.largeMin`; compact/medium продолжают читать base border.
- 2026-09-01 — итоговый routing подтверждён: manifest/generated bindings, Spectator CSS/test и design docs; architecture/domain/data/network не затронуты.

## Результат

Bracket connectors используют component-local semantic width: base на compact/medium/expanded и новый общий emphasis border на large/xlarge. Token добавлен в manifest 1.3.0 и сгенерирован для Flutter/Web, поэтому raw platform-only размер отсутствует.
