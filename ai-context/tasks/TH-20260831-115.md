# TH-20260831-115: Исправить ширину колонки «Место» на Host Finished

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: запрос пользователя; перенос значения в колонке `Место` недопустим.

## Цель

Сделать колонку `Место` на Host Finished достаточно широкой для точных мест и диапазонов (`3–4`) без переноса, сохранив плотность и identity fighter.

## Контекст

Finished — read-only terminal summary. Place/range приходит готовым из application projection; UI не вычисляет и не форматирует domain ranking самостоятельно.

## Границы задачи

### Входит

- Колонка place/range и её responsive layout.
- Long-range, long nickname и 200% text scale regression.

### Не входит

- Изменение ranking engine, tie-break или места участников.
- Типографический redesign остальных колонок.

## Требования и ограничения

- `Место` читается одной строкой во всех поддерживаемых width classes.
- Табличная семантика сохраняется на desktop, compact rows — на mobile.
- Использовать tokens/presets, без raw dimensions.

## Журнал решений

- 2026-08-31 — place/range считается атомарным отображаемым значением; перенос запрещён.
- 2026-08-31 — добавлен additive token `layout.standingsPlaceColumnMin`, manifest поднят до `1.2.0`: причина — структурная колонка не должна зависеть от случайного spacing token; последствие — generated Flutter/Web bindings обновлены; rollback — вернуть прежний token и bindings вместе с компонентом.

Колонка «Место» получила semantic minimum из manifest и однострочные header/value labels. Значения `1`, `3–4` и `10–11` сохраняются атомарными на compact/desktop при 200% text scale, fighter identity и готовая application projection не изменены.
