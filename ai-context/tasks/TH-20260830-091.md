# TH-20260830-091: Реализовать local profile и settings для Host MVP

- Статус: В работе
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P2 implementation plan; prerequisite Host flow.

## Цель

Создать и восстановить один local profile Host, сохранить nickname/settings и безопасно выполнить account reset без потери целостности данных.

## Контекст

App bootstrap/router уже реализованы задачами 086–089, но application пока не имеет profile repository и mutation commands. Participant profile join не входит в MVP.

## Границы задачи

### Входит

- Typed profile model/ports, local persistence, onboarding/edit и non-critical settings.
- Reset profile contract с возвратом в Registration.
- Unit/round-trip/failure tests.

### Не входит

- Participant join/binding, notifications и network identity.
- Tournament aggregate, history и LAN protocol.

## Требования и ограничения

- Profile хранится не в `shared_preferences`; preference store используется только для non-critical settings.
- Nickname trim/non-empty, stable profileId; reset атомарен и recoverable.
