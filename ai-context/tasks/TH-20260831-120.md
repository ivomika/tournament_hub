# TH-20260831-120: Исправить наложение участников в Spectator Current Match

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: скриншот пользователя; identities и центральный `VS` накладываются в текущем матче Spectator.

## Цель

Сделать `MatchupHero` устойчивым на узкой и средней ширине: оба fighter identity, `VS`, score и metadata читаются без overlap/clipping и сохраняют крупный artwork как главный идентификатор.

## Контекст

После task 116 current lane использует dominant matchup composition. На фактической ширине около 700 px горизонтальная grid-композиция не резервирует достаточно места для двух крупных identities и центрального блока.

## Границы задачи

### Входит

- Адаптивная раскладка Spectator `MatchupHero` и связанные component styles.
- Проверка длинных fighter/nickname, narrow/medium/expanded widths и text overflow.
- Presentation regression tests без изменения projection/domain.

### Не входит

- Изменение размера исходных fighter assets, правил турнира, protocol DTO и Dashboard timeline semantics.
- Исправление browser image-toolbar overlay на скриншоте: это внешний control браузера, не часть приложения.

## Требования и ограничения

- Artwork остаётся главным визуальным идентификатором участника.
- Центральный `VS` не перекрывает identity и не вытесняет score/metadata.
- Raw colors/dimensions не добавляются; используются существующие design tokens и component selectors.
- DOM/read order остаётся `первый участник → VS → второй участник`.

## Проверка

- `npm.cmd test` — успешно, 7 файлов / 28 тестов.
- `npm.cmd run check` — успешно (`tsc -b`, `oxlint`).
- `npx.cmd prettier --check src/presentation/components/matchup-hero/MatchupHero.test.tsx src/presentation/design-system/theme.css` — успешно.
- `npm.cmd run format:check` — общий gate не прошёл из-за ранее существующего formatting issue в `src/application/spectator/client.ts`, который не входит в diff задачи 120.
- Browser smoke пропущен: browser runtime не обнаружил ни одного доступного backend; риск компенсирован CSS regression и screen suite, но ручная проверка фактического viewport остаётся желательной.
- `git diff --check` — успешно; только ожидаемые Windows line-ending warnings.
- Production build не запускался по ограничению пользователя.

## Журнал решений

- 2026-08-31 — внешний toolbar над изображением не входит в приложение; исправляется только внутренняя overlap-композиция.
- 2026-08-31 — root cause: более поздний `.identity--reverse` переопределял `flex-direction: column` у `.identity--vertical` второго бойца.
- 2026-08-31 — scoped modifier `.identity--vertical.identity--reverse` сохраняет вертикальную ось; `reverse` продолжает работать для horizontal compact identity.
- 2026-08-31 — итоговый routing подтверждён: diff касается только Web component CSS/test, design canon и task metadata; architecture/domain/data/network contracts не менялись.

## Результат

У второго участника `MatchupHero` больше не сбрасывается vertical layout из-за `reverse`: artwork, fighter name, nickname и guest label остаются в его grid track и не заходят на центральный `VS`. Длинные identity strings получают безопасный перенос. Устойчивое поведение закреплено отдельным regression test и в design canon.
