- Источник: запрос добавить экран финала турнира и реализовать spectator для всех поддерживаемых режимов.

## Цель

После завершения Host-турнира Spectator Web автоматически переходит к read-only финальному экрану с чемпионом, fighter и итоговыми местами, а сквозные tests подтверждают realtime flow обоих форматов от подключения до финала.

## Контекст

Round Robin и Double Elimination формируют разные active projections, но finished experience должен иметь общий каркас и format-specific детали. Переход обязан происходить по авторитетному finished snapshot, а не по локальной догадке web app.

Зависимости: `TH-20260825-012`, `TH-20260825-013`, `TH-20260825-014`.

## Границы задачи

### Входит

- Автоматический переход active → finished по Host snapshot.
- Champion hero с nickname, fighter display name/avatar и форматом турнира.
- Итоговые места всех участников с fighter.
- Round Robin итоговая standings/statistics projection.
- Double Elimination завершённая каноничная bracket и placement replay summary.
- Reconnect непосредственно к уже завершённому турниру.
- Сквозные tests Flutter WebSocket Host ↔ Spectator Web для обоих форматов.
- Локальные команды запуска и документация подключения spectator.

### Не входит

- Редактирование завершённого турнира.
- Общая облачная история нескольких Host.
- Социальные функции, стриминг видео или чат.

## Требования и ограничения

- Финал показывается только после authoritative finished snapshot.
- Изменение актуального roster не переписывает fighter metadata завершённого snapshot.
- Все участники отображаются с fighter либо явным fallback.
- Reconnect к finished Host сразу открывает финал без проигрывания промежуточных events.
- E2E не зависит от случайного seeding: fixtures воспроизводимы.

## Результат

Spectator автоматически следует за authoritative Host snapshot от активного состояния до финала. Новый клиент или reconnect немедленно получает последний snapshot; finished snapshot сразу открывает экран чемпиона, fighter и мест. Round Robin сохраняет итоговую таблицу и матчи, Double Elimination — каноничную завершённую сетку и placement replay. Локальный запуск собирает React и встраивает его в Flutter Host, который показывает LAN URL и QR-код.
