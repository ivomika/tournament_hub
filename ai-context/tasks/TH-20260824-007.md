# TH-20260824-007: Использовать Equatable для сравнения domain-объектов

- Статус: Выполнена
- Создана: 2026-08-24
- Обновлена: 2026-08-24
- Источник: уточнение пользователя использовать Equatable для сравнения объектов.

## Цель

Domain-объекты локального профиля используют единый механизм value equality через Equatable без ручных реализаций `operator ==` и `hashCode`.

## Контекст

В `TH-20260824-003` для `LocalProfile`, `LocalProfileId` и `Nickname` было реализовано ручное сравнение. Пользователь зафиксировал общую техническую конвенцию Equatable.

Связанная задача: `TH-20260824-003`.

## Границы задачи

### Входит

- Подключение Equatable.
- Перевод domain-объектов профиля на `Equatable`.
- Закрепление правила для будущих вручную написанных value objects/entities.
- Повторный запуск domain-тестов и анализа.

### Не входит

- Замена Freezed equality в generated data models.
- Изменение поведения сущностей или правил nickname.

## Требования и ограничения

- Не дублировать `operator ==` и `hashCode` вручную.
- Freezed-модели продолжают использовать сгенерированное сравнение.
- Список `props` содержит только поля, определяющие value equality объекта.

## План

1. Добавить Equatable в зависимости приложения.
2. Перевести domain-объекты профиля на `Equatable`.
3. Зафиксировать командное правило в `AGENTS.md`.
4. Запустить domain-тесты и статический анализ.

## Критерии приёмки

- [x] Domain-объекты профиля наследуются от Equatable.
- [x] Ручные реализации equality удалены.
- [x] Поведение equality и сохранения identity покрыто тестами.
- [x] Правило разработки обновлено.
- [x] Тесты и анализ проходят.

## Проверка

- `flutter test test/features/profile/domain`: 5 тестов прошли, включая value equality.
- `flutter analyze lib/features/profile/domain test/features/profile/domain`: проблем не обнаружено.
- Полный `flutter analyze` временно обнаружил две проблемы в незавершённой `TH-20260824-004`; они относятся к persistence-коду и будут устранены в этой активной задаче.

## Журнал решений

- 2026-08-24 — Equatable применяется к вручную написанным domain entities/value objects; Freezed сохраняет собственную generated equality.

## Результат

Подключён Equatable. `LocalProfile`, `LocalProfileId` и `Nickname` используют `props`; ручные `operator ==` и `hashCode` удалены. Добавлен тест равенства независимых экземпляров, а правило закреплено в `AGENTS.md`. Freezed data models сохраняют собственную generated equality.
