# TH-20260831-107: Исправить Spectator URI, копирование и 404

- Статус: Выполнена
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: пользовательский аудит Spectator access.

## Цель

Показывать и копировать полный HTTP URI Spectator в LAN, а переход по нему должен открывать реально обслуживаемый Spectator entry без 404.

## Контекст

Кнопка «Копировать текущий» копирует неясный код вместо ссылки, термин «текущий» не объясняет действие, а отображаемый адрес приводит к 404.

## Границы задачи

### Входит

- Явная подпись действия «Копировать ссылку Spectator».
- Копирование полного `http://<ip>:<port>/...` URI и feedback success/failure.
- Согласование Host static serving, route и fallback entry для Spectator.
- Empty/unavailable endpoint state без ложного success.

### Не входит

- Аутентификация, expiry, session binding и новый protocol envelope.
- Публикация за пределы LAN или production security hardening.

## Требования и ограничения

- Формат URI остаётся локальным HTTP IP+port по решению пользователя.
- Host authority и read-only Spectator contract сохраняются.
- OD-002/OD-003 не закрываются этой задачей.
