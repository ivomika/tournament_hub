# TH-20260830-092: Реализовать Host tournament aggregate и Guests

- Статус: Готова
- Создана: 2026-08-30
- Обновлена: 2026-08-30
- Источник: P3 implementation plan и Host-only MVP scope.

## Цель

Реализовать чистый Domain aggregate Host tournament с lifecycle Draft→Open→Distribution→Running→Finished/Cancelled, локальными Guests, IDs, revision и command guards.

## Контекст

Domain rules уже задают lifecycle, min/max participants, Guest semantics и immutable terminal outcomes; production Domain package пока отсутствует.

## Границы задачи

### Входит

- Typed IDs, immutable snapshot, participants/profile/Guest sources, lifecycle commands.
- Validation, one active tournament invariant boundary contract и audit metadata.
- Domain unit/property/invariant tests.

### Не входит

- Format-specific progression/results/scoring engines (095).
- Persistence/Drift (093), LAN protocol и Participant state.

## Требования и ограничения

- Host — единственный authority; Guest network identity не создаётся.
- Domain не импортирует Flutter/Riverpod/Drift/JSON/sockets.
- Navigation не является lifecycle mutation.
