# TH-20260831-116: Перестроить Spectator Dashboard по временным lanes

- Статус: Готова
- Создана: 2026-08-31
- Обновлена: 2026-08-31
- Источник: запрос пользователя и screenshot completed match card.

## Цель

На Spectator/Эфире выстроить матчи по временной логике: завершённые слева, текущий по центру, будущие справа; исправить переполнение и наложение fighter/name/score в completed card.

## Контекст

Dashboard — read-only projection. Порядок и статусы приходят из Host projection; React не рассчитывает progression. Screenshot показывает, что узкая карточка допускает конфликт имени, score и identity.

## Границы задачи

### Входит

- Lanes `Завершённые → Сейчас → Будущие` с явными заголовками.
- Completed/current/upcoming card variants, длинные fighter names и score/result labels.
- Responsive composition без потери временной ориентации.

### Не входит

- WebSocket protocol/schema и Host projection semantics.
- Каноничный bracket screen (task 117).

## Требования и ограничения

- Current match визуально доминирует и остаётся в центральной зоне.
- В completed card fighter artwork, name, nickname, guest label и результат не пересекаются.
- У completed матчей не должно быть ложного `0` рядом с именем из-за неверной сетки.
