# TH-20260825-013: Добавить spectator dashboard и Round Robin

- Статус: Выполнена
- Создана: 2026-08-25
- Обновлена: 2026-08-25
- Источник: запрос добавить экран dashboard и поддержать все режимы Host-приложения.

## Цель

Spectator dashboard в реальном времени показывает идентичность турнира, участников с бойцами, прогресс и актуальное состояние Round Robin без возможности изменить Host state.

## Контекст

Round Robin использует раунды, best-of-three результаты и standings, поэтому его spectator-представление отличается от Double Elimination. Dashboard должен давать общий вход в текущий турнир и переходить к format-specific представлению.

Зависимость: `TH-20260825-012`. Условие готовности — spectator store предоставляет typed Round Robin snapshot.

## Границы задачи

### Входит

- Общий dashboard active tournament: название, формат, статус соединения, прогресс и участники с fighter.
- Round Robin rounds/matches, `bye`, текущий/итоговый счёт best-of-three и standings.
- Ясное выделение текущих незавершённых матчей и последних подтверждённых результатов.
- Loading/empty/disconnected/stale states.
- Mobile browser, tablet, desktop/TV responsive layout и accessibility.

### Не входит

- Double Elimination bracket — `TH-20260825-014`.
- Финальный экран — `TH-20260825-015`.
- Управление результатами со стороны spectator.

## Требования и ограничения

- Dashboard отображает только projection Host и не начисляет очки самостоятельно.
- Каждый участник показывается с nickname, fighter display name и avatar либо явным fallback.
- Критичная информация не требует горизонтальной прокрутки, если может быть адаптирована композицией.
- Изменение revision обновляет только presentation state без потери scroll/focus, где это возможно.

## План

1. Определить общую dashboard navigation и visual states.
2. Реализовать participant/progress/realtime status components.
3. Реализовать Round Robin rounds, matches и standings projection.
4. Добавить responsive, accessibility и live-update tests.
