# TH-20260828-051: Выравнять Host tournament flow по новому visual language

- Статус: Черновик
- Создана: 2026-08-28
- Обновлена: 2026-08-28
- Источник: продолжение задачи 049 по запросу пользователя; запускать после подтверждения результата 049

## Цель

Привести `Host Draft`, `Host Open`, `Host Distribution`, `Host Running`, `Host Result Entry`, `Host Finished` и `Host Cancelled` к одной выразительной турнирной композиции с ясным stage/progress, matchup и champion hierarchy.

## Контекст

Host flow — основной сценарий продукта и главный потребитель `MatchCard`, `ParticipantIdentity`, `ChampionHero`, `Standings` и tournament progress. Задача 049 задаёт baseline для этих компонентов, а эта карточка переносит его на полный lifecycle без изменения domain behavior.

## Границы задачи

### Входит

- Stage header/progress и визуальное разделение Draft/Open/Distribution/Running/Finished.
- Matchup/current match/result entry с artwork variant `matchup`, outcome и correction path.
- Distribution roster с полной fighter identity и понятным primary start action.
- Finished/Champion с hero treatment, ranking и read-only structure.
- Cancelled/error/empty/loading/disabled states и adaptive desktop composition.
- Widgetbook use cases и screenshot/golden evidence для всех Host states.

### Не входит

- Изменение tournament engine, scoring, bracket progression, correction или persistence.
- Изменение существующих Host routes и команд.

## Требования и ограничения

- Предшественник: 049; задача активируется только после его visual review.
- Все participant упоминания после assignment показывают fighter artwork, fighter name и nickname.
- Double Elimination visual structure не упрощать до generic grid; canonical semantics должны оставаться читаемыми в адаптивной композиции.
