# TH-20260830-099: Реализовать Host LAN server для Spectator

- Статус: Выполнена
- Создана: 2026-08-30
- Обновлена: 2026-08-31
- Источник: P10 Host LAN/Spectator implementation.

## Цель

Запустить на Host локальный HTTP/static server и WebSocket publisher, который отдаёт только утверждённую Spectator projection и не влияет на tournament progression.

## Контекст

Technology baseline фиксирует Shelf/shelf_router/shelf_static/shelf_web_socket. Contract 098 завершён commit `d700691`; OD-013 закрывается ADR-0012 до server code.

## Границы задачи

### Входит

- Server lifecycle, bind diagnostics, static React bundle, HTTP snapshot endpoint и WebSocket events.
- Publish-after-commit, client limits, malformed payload handling, stale/rebind/failure state.
- Host integration and server lifecycle tests.

### Не входит

- Participant transport, QR/join/reconnect.
- React visual implementation (100), domain engine.

## Требования и ограничения

- Progression работает без LAN; publish failure только degraded status.
- Spectator не может отправлять tournament commands.
- Secrets/addresses/diagnostics не попадают в public projection/logs.

## Проверка

- `flutter analyze` — успешно, 0 issues.
- 217 non-golden tests — успешно; targeted suite `spectator_host_integration`, projection factory и LAN server — 7 tests, успешно.
- `dart run tool/project.dart architecture` — оба layer/design-system gate прошли.
- Проверены static GET/HEAD, snapshot GET, mutation 405/404, same-origin, malformed/oversized handshake, WebSocket sync/event, port fallback и stop/restart.
- Production build и platform manual LAN checks не запускались по прямому запрету пользователя; Participant transport и Internet deployment не выполнялись по scope.

## Журнал решений

- 2026-08-30 — Spectator server — отдельный optional Host service; его availability не является tournament invariant.
- 2026-08-31 — Public participant IDs формируются заново в tournament scope; внутренние profile/guest IDs не пересекают projection boundary.
- 2026-08-31 — HTTP routing реализован Shelf Router, static delivery — shelf_static, realtime — shelf_web_socket; terminal finished закрывает live sockets, сохраняя HTTP snapshot.

## Результат

Реализован optional Host LAN server с preferred/ephemeral bind, safe lifecycle diagnostics, static bundle, HTTP snapshot, strict read-only WebSocket handshake/sync/replay и public projection v1. Composition сериализует публикации после committed Host session и изолирует start/publish failures от progression; Host/Open показывает реальный endpoint, client count и safe recovery state.
