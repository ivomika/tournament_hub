# Документация и assets

- Ищи канон через `docs/README.md`; не используй `docs/source` вместо нормализованных требований.
- Изменение behavior/schema/protocol/token обновляет owning document в той же задаче.
- Термины сверяй с glossary; user text на русском, identifiers технические.
- Относительные Markdown-ссылки должны быть валидны.
- Fighter IDs/filenames стабильны; import проверяет manifest, dimensions и missing/unlisted files.
- Artwork после assignment — identity, не background decoration.
- Не редактируй source assets попутно и не публикуй их без license/provenance gate.
