# Task workflow

## Trigger

Всегда для любой работы в репозитории.

## Обязательно

- До изменения файлов создать/актуализировать одну карточку `В работе` и связать её с реестром.
- Зафиксировать scope, non-scope, канон, rule profile, plan, criteria и ожидаемые checks.
- При изменении scope сначала обновить карточку и conditional rule routing.
- Перед завершением записать фактические checks/result и синхронизировать статус.

## Запрещено

- Начинать изменение без активной карточки.
- Держать одновременно больше одной своей задачи `В работе`.
- Помечать задачу выполненной при невыполненном обязательном evidence.
