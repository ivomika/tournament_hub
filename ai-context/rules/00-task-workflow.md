# Task workflow

- До изменений прочитай `AGENTS.md`, `ai-context/README.md`, `task-list.md` и весь индекс rules.
- Найди связанную карточку либо создай новую по шаблону; не переиспользуй `NNN`.
- Заполни goal, context, scope/non-scope, rules links, plan, criteria и checks до реализации.
- Одновременно веди только одну свою задачу `В работе`; синхронизируй статус и emoji.
- Изменился scope — сначала обнови карточку и план.
- В конце запиши фактические checks, limitations и result; только затем ставь `Выполнена`/✅.
- `$task` только записывает декомпозицию; реализация — отдельный этап.
