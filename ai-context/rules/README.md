# Обязательные правила перед каждой задачей

Перед переводом любой задачи в `В работе` исполнитель обязан прочитать все файлы этого каталога по порядку. Частичное чтение допускается только для повторного просмотра в рамках той же непрерывной задачи; новый task ID начинает новый цикл чтения.

## Ссылка из карточки

Каждая карточка содержит раздел `Обязательные правила` со ссылкой на этот индекс и прямыми ссылками на особенно затронутые правила. Отсутствие раздела означает, что карточка не готова к реализации.

Полное объяснение находится в [`docs`](../../docs/README.md); эти файлы — короткий исполняемый gate, а не замена документации.
