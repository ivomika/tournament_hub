# Правила проекта

Этот файл — router правил. Перед любым изменением репозитория нужно прочитать его целиком, затем все перечисленные обязательные правила и применимые conditional rules.

## Обязательные правила

- [R-001 · SOLID](core/001-solid.md) — применяется к любому изменению кода, модулей и архитектурных границ.
- [R-002 · Документирование на русском](core/002-documentation-russian.md) — применяется к изменениям требований, поведения, контрактов, архитектуры и решений.

## Нумерация

- Каждый rule получает уникальный сквозной идентификатор `R-NNN`.
- Номер не зависит от даты, статуса или расположения правила и не переиспользуется.
- Номер указывается в названии файла, заголовке, router и карточках задач.

## Порядок работы

1. Прочитать этот router и все обязательные правила.
2. Прочитать `ai-context/task-list.md` и связанную карточку задачи, если она есть.
3. Определить conditional rules по scope задачи и прочитать только сработавшие.
4. Зафиксировать в карточке номер каждого применимого rule и то, как он изменил план, границы, критерии или проверки.

Правила не заменяют прямые требования пользователя и не дают разрешения расширять scope задачи.
