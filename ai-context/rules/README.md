# Правила проекта

Этот файл — router правил. Перед любым изменением репозитория нужно прочитать его целиком, затем все перечисленные обязательные правила и применимые conditional rules.

## Обязательные правила

- [SOLID](core/solid.md) — применяется к любому изменению кода, модулей и архитектурных границ.

## Порядок работы

1. Прочитать этот router и все обязательные правила.
2. Прочитать `ai-context/task-list.md` и связанную карточку задачи, если она есть.
3. Определить conditional rules по scope задачи и прочитать только сработавшие.
4. Зафиксировать в карточке, какие rules применимы и как они изменили план, границы, критерии или проверки.

Правила не заменяют прямые требования пользователя и не дают разрешения расширять scope задачи.
