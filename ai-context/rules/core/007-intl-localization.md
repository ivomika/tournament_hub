# R-007. Обязательная локализация через intl

## Применение

Обязательное правило. Проверяется при добавлении текста, сообщений ошибок, semantics, подсказок и форматирования в UI.

## Ограничения

- Весь текст интерфейса получается через типизированный API локализации на основе `intl`. Прямые литералы, обычные строковые константы и ручные словари переводов запрещены.
- Заголовки, кнопки, подсказки, accessibility/semantics, валидация и пользовательские ошибки входят в локализацию.
- Параметры, plural/select, даты и числа оформляются через локализацию/intl с текущей locale. Нельзя собирать перевод конкатенацией или вручную выбирать окончания.
- Domain возвращает типизированные результаты и причины ошибок. Перевод в UI-сообщение выполняется в presentation; domain не импортирует intl или UI-localizations.
- Исключение для служебного текста — диагностическое логирование. Сообщение лога нельзя напрямую показывать пользователю.
- Пользовательские данные и строковые представления протоколов не являются переводами; их обработка подчиняется R-006.

## Проверка

Проверить источник каждого нового UI-текста, параметры локализованного сообщения и использование locale при форматировании. Переводы хранятся в ресурсах локализации, а не в константах widgets/state.
