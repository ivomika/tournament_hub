## Ключевые решения

- Progressive disclosure — основной принцип карты: сначала areas, затем clusters, затем конкретные edges.
- «Фокус связей» остаётся явным действием пользователя; default state показывает полную карту без предвзятого стартового узла.
- По обратной связи на приёмке этапа 1 горизонтальный коридор между карточками увеличен сильнее вертикального; допустимая цена — более широкая карта с горизонтальной прокруткой.
- Обзор областей и drill-down из этапа 2 отклонены пользователем и удалены из scope; карта остаётся единой кластерной схемой.
- Агрегированные шины из этапа 3 отклонены пользователем и удалены из кода. Сохраняются отдельные исходные edges; их межкластерный характер будет показан пунктиром на этапе 5.
- Межкластерность определяется только сравнением `area` исходного и целевого узла. JSON inventory, labels и поведение выбора не меняются.
- Коммиты выполняет пользователь. Агент на каждой точке приёмки предоставляет только короткий пример сообщения без команды.
