# Задача 19. Добавить управление масштабом и высотой карты в Domain viewer

## Статус

✅ Выполнена

## Цель

Дать пользователю возможность уменьшать и увеличивать карточки вместе со всей картой, видеть текущий масштаб и вписывать полную Domain-карту в доступный viewport.

## Контекст и границы

- Высота viewport остаётся автоматической по размеру окна, как до ошибочной первой реализации задачи.
- Масштабируются graph canvas, карточки, кластеры, подписи и связи как единое целое.
- Доступны `−`, `+`, range control, `100%` и режим «Вписать».
- Ручной масштаб сохраняется между запусками; «Вписать» пересчитывается при изменении карты или окна.
- Масштаб не меняет generated data, graph layout и семантику связей.
- Изменения Domain generator, generated schema и Domain-кода не входят.
- Горизонтальная компоновка остаётся прежней: общий layout ограничен `1600px`, Details постоянно занимает свою колонку.
- Минимальная высота самого `graph-viewport` равна высоте окна за вычетом header карты.
- Panel header сохраняет прежнюю двухуровневую компоновку пояснения и zoom controls.

## Ключевые решения

- Ошибочная ручная высота и resize handle полностью удалены; `syncViewerHeight` снова использует исходный автоматический расчёт.
- Масштабируется единый `graph-canvas`, содержащий clusters, nodes и SVG edges; `graph-stage` задаёт масштабированный scroll extent.
- Ручной диапазон составляет `10–200%`: range control использует шаг `5%`, кнопки — `10%`.
- «Вписать» выбирает меньший коэффициент по доступной ширине и высоте с суммарным запасом `24px` и пересчитывается при render/resize.
- Геометрия edges рассчитывается из фактических `layout.nodePositions` в естественных координатах canvas, поэтому CSS scale не применяется к координатам повторно.
- При ручном zoom сохраняется точка в центре viewport; карта меньшего размера центрируется внутри viewport.
- Ручной коэффициент сохраняется под ключом `tournamentHub.domainCheck.graphScale`; «Вписать» очищает его.
- Расширение layout до `2400px`, сворачивание Details и однострочный header были отклонены на приёмке и полностью удалены.
- Ширина возвращена к `1600px` с внешним отступом `24px`; Details снова является постоянной колонкой `310px`.
- Минимальная высота внутреннего graph viewport вычисляется как `window.innerHeight - panelHeader.offsetHeight`, с нижней границей `320px`; высота всей architecture panel равна сумме этих значений.
