# Задача 27. Композиция widgets и аудит правил

## Статус

✅ Завершена

## Цель

Добавить обязательные правила извлечения widgets и именованных callbacks, а также локальный skill для аудита соответствия кода актуальным правилам.

## Контекст и границы

- Scope skill: diff по умолчанию, весь код или код указанной задачи из task-list.
- Skill перечитывает правила, проверяет их согласованность и затем код; выдаёт доказанные findings без автоматического исправления.
- В этой задаче код приложения не рефакторится и аудит всего проекта не выполняется.

## Ключевые решения

- Правила обязательны; аудит вызывается пользователем и по умолчанию не изменяет репозиторий.
- Skill хранит workflow, а актуальные требования читает из router; противоречия правил отделяются от доказанных нарушений кода.
- Scope задачи требует подтверждённых paths/refs. При недостаточной привязке skill сообщает ограничение, не присваивая задаче чужой diff.
- Настройка skill-creator применена: skill компактный, без дополнительных scripts/resources, implicit invocation отключён по требованию пользовательского вызова.

## Проверки

- Ссылки, формат skill/policy и diff-check проверены. Стандартный Python-валидатор недоступен из-за PyYAML; ограничение записано выше. Билды и аудит приложения не выполнялись.

Два обязательных правила и локальный skill аудита добавлены с документацией и тремя режимами scope. Код приложения не изменялся. Skill не заменяет автоматический lint и не заявляет полное соответствие проекта без отдельного аудита. Коммит не создавался.
