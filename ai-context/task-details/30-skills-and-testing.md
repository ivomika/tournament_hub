# Задача 30. Skills и обязательное тестирование

## Статус

✅ Завершена

## Цель и границы

Единый каталог локальных skills `.agents/skills` и обязательное core-правило тестирования. Код приложения, глобальные настройки Codex и существующая семантика skills не меняются.

## Применимые правила

- R-001 — проверка поведения отделяется от workflow задач; перемещение skill не меняет его ответственность.
- R-002 — политика тестирования и расположение skills документируются в docs.
- R-004 — нет изменений контрактов/типов приложения; сохраняются типизированные проверки tooling.
- [R-007](../rules/core/007-code-testing.md) — создано в задаче; для документации и перемещения skills выбраны структурные проверки и сравнение содержимого.
- Прочитаны core rules и maintenance; Flutter rules неприменимы к изменению расположения skills и общей политики. Conditional rules отсутствуют.

## Декомпозиция и критерии

- [x] Перенести task skill и метаданные в .agents, без дублирования и изменения содержимого.
- [x] Добавить R-007 в core, router и registry; описать поведенческие тесты и требования к фактической проверке.
- [x] Обновить документацию и проверку code-rules-audit на применение R-007.
- [x] Проверить реестр, ссылки, целостность перемещения и отсутствие файлов .codex.

**Изменения**

- Task skill перенесён в .agents/skills/task вместе с openai.yaml; пустая .codex удалена. Перемещение защищённых папок выполнено с разрешённым выходом из sandbox после проверки абсолютных путей.
- Добавлены core R-007, политика тестирования в docs, описание локальных skills. Обновлены router, registry, maintenance, индекс docs и шаблон задачи.
- Skill code-rules-audit проверяет покрытие и сведения о запуске по R-007, различая отсутствие теста и отсутствие записи о запуске.

**Проверки**

- SHA-256 SKILL.md и openai.yaml до/после переноса совпали: содержимое task skill сохранено полностью.
- `.codex` отсутствует; в .agents есть только два требуемых skills, без дублей. Активных ссылок на .codex в руководствах и skills нет; исторические журналы не переписаны.
- `node tools/check_rules.cjs` — успешно: 12 leaf, 2 группы; ссылки 61 Markdown-файла, frontmatter/имена обоих skills, explicit-only policy и `git diff --check` проверены.
- Runtime-код не менялся; тесты приложения и билды не запускались. Проверены документация, метаданные и workflow выбора/применения нового правила; стандартный skill-validator с PyYAML не использовался.

## Решения

- Все репозиторные skills располагаются в .agents/skills, каждый в своей папке с неизменным именем.
- Тесты проверяют поведение/инварианты и регрессии; для документации и метаданных применяются структурные проверки.

## Итог

Локальные skills объединены в .agents, core-правило обязательного тестирования зарегистрировано и документировано. Удалены только прежнее расположение task skill и оставшиеся пустые .codex-папки; содержимое сохранено в новом месте. Перенос восстанавливается из Git или обратным перемещением. Коммит не создавался.
