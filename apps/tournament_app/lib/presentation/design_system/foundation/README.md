# Foundation

Реализованные scopes базовых токенов и общая тема дизайн-системы. Цвета и типографика реализованы по выбранному foundation; новые scopes добавляются по мере потребности.

Структура и контракт: [архитектура presentation](../../../../../../docs/architecture/presentation-ui.md).

Значения и выбор: [foundation](../../../../../../docs/design/foundation.md) и [manifest](../../../../../../docs/design/tokens-manifest.md).
