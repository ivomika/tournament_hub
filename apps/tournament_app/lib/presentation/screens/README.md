# Screens

Каждый реализованный screen имеет свою папку, тему, presentation-контракт и golden/. Запускается отдельно с preview-контрактом; не содержит бизнес-логики или кастомных компонентов вне DS.

Контракт: [архитектура presentation](../../../../../docs/architecture/presentation-ui.md). Процесс: [golden и Widgetbook](../../../../../docs/development/visual-workflow.md).
