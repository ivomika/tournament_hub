# Tournament App

Flutter-приложение Tournament HUB для ролей Host и Participant.

## Локальный запуск

Из корня репозитория:

```bash
make flutter-get
make run-flutter
```

Архитектурные границы и ответственность модулей описаны в корневом `AGENTS.md`.
