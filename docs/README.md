# Документация

Этот каталог преобразует исходный технический дизайн в поддерживаемую документацию проекта.

- `architecture/overview.md` — границы компонентов и потоки состояния.
- `product/platform-and-responsive-ui.md` — приоритет мобильных устройств и требования к адаптивному UI.
- `product/open-decisions.md` — решения, которые намеренно не зафиксированы текущим дизайном.
- `protocol/README.md` — правила локального протокола и планируемые контракты.
- `tournament/README.md` — подтверждённые доменные правила и инварианты.
- `adr/` — записи архитектурных решений.

Исходный дизайн-документ хранится вне репозитория. При изменении поведения или контракта документация репозитория обновляется одновременно с реализацией.
