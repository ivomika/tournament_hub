# Ростер Mortal Kombat 11 Ultimate

Для локальных турниров используется полный состав Mortal Kombat 11 Ultimate из 37 бойцов.

Состав проверен по официальным материалам WB Games:

- [анонс основной игры](https://warnerbrosgames.com/article/official-mortal-kombat-11-launch-announcement) — 25 бойцов основной игры, включая Shao Kahn;
- [официальный FAQ Mortal Kombat 11 Ultimate](https://mortalkombatgamessupport.wbgames.com/hc/en-us/articles/360055513674-Mortal-Kombat-11-Ultimate-FAQ) — Kombat Pack 1, Aftermath и Kombat Pack 2.

Каноническим источником приложения является заменяемая реализация `Mk11UltimateFighterRegistry`. Порядок, stable ID и `avatarId` покрываются тестом. Display name можно локализовать независимо от stable ID.

## Состав

- Основная игра: Baraka, Cassie Cage, Cetrion, D'Vorah, Erron Black, Frost, Geras, Jacqui Briggs, Jade, Jax Briggs, Johnny Cage, Kabal, Kano, Kitana, Kollector, Kotal Kahn, Kung Lao, Liu Kang, Noob Saibot, Raiden, Scorpion, Shao Kahn, Skarlet, Sonya Blade, Sub-Zero.
- Kombat Pack 1: Shang Tsung, Nightwolf, Sindel, Terminator T-800, The Joker, Spawn.
- Aftermath: Fujin, Sheeva, RoboCop.
- Kombat Pack 2: Mileena, Rain, Rambo.
