# Расположение приложений

## Решение

Клиентское приложение TournamentHUB располагается в `apps/tournament_app`.

Ответственность слоёв внутри клиента и разрешённые зависимости определены в [архитектуре слоёв](layer-boundaries.md).

## Границы

- Корень репозитория хранит общие инструкции, документацию и процесс работы.
- `apps/tournament_app` — самостоятельный Flutter-проект.
- `tools/` — утилитарная папка проекта для скриптов и вспомогательных инструментов, не являющихся частью runtime-кода приложения.
- Приложение поддерживает Android, iOS, Linux, macOS, Windows и Web.

## Последствия

Команды Flutter выполняются из `apps/tournament_app`. Будущие приложения могут быть добавлены в `apps/` без смешения с исходным кодом существующего клиента.
