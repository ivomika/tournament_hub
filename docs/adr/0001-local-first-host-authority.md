# ADR-0001: Local-first и авторитетность Host

- Статус: Принято
- Дата: 2026-08-24

## Контекст

Основной турнирный сценарий должен работать без публичного backend и подключения к интернету. Распределённое разрешение конфликтов излишне усложняет MVP.

## Решение

Flutter-приложение Host владеет авторитетным состоянием активной группы и турнира и сохраняет его локально. Participants отправляют намерения и получают snapshot/event. React-клиенты Spectator получают только read projection. При первом подключении и reconnect используется полный snapshot, после чего инкрементальные обновления упорядочиваются монотонной revision.

## Последствия

Турнир работает в локальной сети, а ответственность за разрешение конфликтов определена однозначно. Доступность Host становится зависимостью сессии, поэтому обязательны локальное сохранение, состояние reconnect и явное отображение потери Host. Миграция Host не входит в MVP.
