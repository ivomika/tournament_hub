# ADR-0003: Встроенный LAN Host для Spectator Web

- Статус: Принято
- Дата: 2026-08-25

## Контекст

Spectator должен открывать актуальный турнир на телевизоре или другом устройстве без установки приложения, публичного backend и доступа в интернет. Flutter Host остаётся единственным источником истины local-first турнира.

## Решение

Flutter Host запускает внутри процесса HTTP- и WebSocket-серверы, доступные в локальной сети. HTTP раздаёт встроенный production bundle Spectator Web и fighter assets, WebSocket `/ws` публикует версионированный read-only snapshot после подтверждённых persistence transitions.

Host показывает единый HTTP URL текстом и QR-кодом и позволяет его копировать. Доступ публичен внутри LAN, без authentication. Подключение и reconnect получают полный snapshot; web не вычисляет tournament rules.

## Последствия

Турнир и spectator работают без интернета и отдельного развёртывания. Host должен корректно управлять lifecycle сервера, выбирать доступный LAN address и переживать сетевые ошибки, не блокируя локальный турнир. Публичный доступ означает, что любой пользователь той же LAN может читать публичную projection; персональные и несвязанные исторические данные в неё не включаются.
