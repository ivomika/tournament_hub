# Читаемость имён и условий

Решение задачи104: общая ответственность core-группы R-008, два отдельных ограничения: [имена](../../ai-context/rules/core/008-a-readable-names.md) и [условия](../../ai-context/rules/core/008-b-explicit-conditions.md). Имена объясняют роль данных; сложный выбор получает именованный метод с if/switch.

## Автоматизация

tools/domain-check/lib/code_readability.dart использует существующий analyzer AST; подключён к inspect архитектурного checker. make architecture-check проверяет Flutter lib/test, make architecture-test сначала запускает fixtures читаемости, затем существующие регрессии и полный scan. Инструмент не обращается к агентам, не исправляет исходники и не использует словарь для угадывания смысла.

Имена проверяются в declarations/parameters/patterns/loops/catch. Private prefix снимается перед анализом; проверяются однобуквенность и целые сегменты ctx/cfg/args, а не подстроки. id/url/uri допустимы. Это детерминированный минимальный фильтр, а не гарантия осмысленности всех имён.

Координатное исключение намеренно узкое: явный числовой тип, локальный x/y, непосредственно paint, прямой extends CustomPainter и известный Flutter import (с учётом prefix/show/hide). Другие контексты требуют отдельного решения. Используется синтаксический AST, не разрешённая модель всех типов проекта: indirect inheritance/reexports/alias typedef не дают автоматического исключения.

Вложенный ConditionalExpression диагностируется во всех трёх частях внешнего выражения, скобки/аргументы не скрывают вложенность. Тела самостоятельных функций отделены. Независимые ?: разрешены. Строки/комментарии не создают findings.

## Последствия

Ранее допустимый код может сделать полный scan красным. Это не повод ослаблять проверку или обновлять fixtures для сокрытия нарушений. Существующие нарушения фиксируются отчётом отдельно от GREEN тестов checker; массовое исправление не входит в задачу104. Библиотечные API, generated и framework overrides не получают неявных исключений. Прочие языки пока проверяются review. [Первичный полный отчёт](../../ai-context/task-details/104-code-readability-report.md) — снимок на2026-11-10, актуальное состояние определяет новый запуск checker.
