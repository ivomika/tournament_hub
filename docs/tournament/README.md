# Домен турнира

## Реализованный первый этап

Tournament draft создаётся локально на одном устройстве из обязательного профиля владельца и гостей. Минимальный состав — два участника. Каждый участник сохраняется как самостоятельный snapshot с source `localProfile` или `guestProfile`; nickname исходного профиля не является живой ссылкой.

Создание draft не назначает бойцов и не запускает матчи. Эти правила добавляются отдельными подтверждёнными задачами поверх сохранённого состава.

## Целевая модель MVP

MVP использует агрегат Tournament формата round robin: расписание по раундам, обычные и технические результаты, уникальное назначение бойцов, standings projection, этапы tie-break и неизменяемый итоговый snapshot.

Основные инварианты:

- Игрок не играет сам с собой.
- До изменения состава каждая основная пара встречается ровно один раз.
- Игрок участвует не более чем в одном основном матче раунда.
- Каждый активный игрок имеет одного бойца, бойцы не повторяются.
- Standings полностью воспроизводится из участников, матчей и результатов.
- Повторное применение одного результата не меняет итог второй раз.
- История завершённых матчей сохраняется при выходе игрока и позднем изменении состава.
- Завершённый турнир не содержит неразрешённых ничьих по местам.

Система очков и порядок стандартных tie-break критериев остаются открытыми продуктовыми решениями.
