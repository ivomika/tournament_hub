# Правила турниров для локального приложения MK11

## 1. Общие принципы

Приложение ориентировано на локальные турниры по Mortal Kombat 11.

Поддерживаемые режимы турниров:

- **Double Elimination (DE)** — основной режим.
- **Single Elimination (SE)** — дополнительный режим.
- **Round Robin (RR)** — дополнительный режим.

Минимальное количество участников для любого турнира — **2 игрока**.

До старта турнира состав участников можно менять без ограничений.

После старта турнира:

- новых участников добавлять нельзя;
- существующего игрока можно только снять с турнира;
- снятие выполняет организатор.

Начальная расстановка игроков в DE и SE формируется **полностью случайно**.

Bye также распределяются **случайным образом**.

---

## 2. Глоссарий

### FT — First To

**FT (First To)** — формат сета, в котором побеждает игрок, первым набравший указанное количество побед.

Примеры:

- **FT1** — первый до 1 победы.
- **FT2** — первый до 2 побед.
- **FT3** — первый до 3 побед.

Стандартное значение для турниров DE и SE — **FT1**.

Если организатор не меняет настройку, матчи играются до одной победы.

---

## 3. Double Elimination (DE)

Double Elimination — основной режим турнира.

Игрок выбывает после двух поражений:

- 0 поражений — игрок находится в Winners Bracket;
- 1 поражение — игрок переходит в Losers Bracket;
- 2 поражения — игрок выбывает из турнира.

Повторные встречи между одними и теми же игроками разрешены.

### 3.1. Bracket Reset

Bracket Reset используется всегда.

В Grand Final встречаются:

- победитель Winners Bracket, у которого 0 поражений;
- победитель Losers Bracket, у которого 1 поражение.

Если игрок из Winners Bracket выигрывает Grand Final, турнир заканчивается.

Если игрок из Losers Bracket выигрывает Grand Final:

- игрок из Winners получает первое поражение;
- у обоих игроков становится по одному поражению;
- проводится второй финальный сет — Bracket Reset.

Победитель Bracket Reset становится чемпионом.

### 3.2. Настройка FT

Для основной сетки используется один общий FT.

По умолчанию:

- основная сетка — **FT1**;
- Grand Final — использует тот же FT.

Организатор может отдельно настроить FT для Grand Final.

Если происходит Bracket Reset, он использует тот же FT, который настроен для Grand Final.

Пример:

- основная сетка — FT1;
- Grand Final — FT3;
- Bracket Reset — FT3.

### 3.3. Bye

Bye — автоматический проход игрока в следующий раунд без проведения матча.

Правила Bye:

- не считается победой;
- не имеет счёта;
- не считается сыгранным матчем;
- не влияет на статистику;
- автоматически переводит игрока в следующий раунд;
- в DE игрок после Bye остаётся с 0 поражений;
- Bye распределяются случайным образом.

### 3.4. Итоговый рейтинг

После завершения турнира формируется **полный итоговый рейтинг всех участников**.

В частности:

- 1 место — победитель Grand Final / Bracket Reset;
- 2 место — проигравший финального противостояния;
- 3 место — проигравший Losers Final;
- остальные места определяются по стадии, на которой игрок выбыл.

---

## 4. Single Elimination (SE)

В Single Elimination одно поражение означает вылет из турнира.

Начальная сетка формируется случайным образом.

### 4.1. Настройка FT

Для основной сетки используется один общий FT.

По умолчанию — **FT1**.

Финал по умолчанию использует тот же FT, что и основная сетка.

Организатор может отдельно настроить FT для финала.

### 4.2. Bye

Правила Bye такие же, как в DE:

- Bye не считается победой;
- не имеет счёта;
- не влияет на статистику;
- автоматически переводит игрока в следующий раунд;
- распределяется случайным образом.

### 4.3. Итоговый рейтинг

Формируется полный итоговый рейтинг.

При этом отдельный матч за третье место не проводится.

Оба проигравших полуфиналов делят позиции **3–4**.

---

## 5. Round Robin (RR)

В Round Robin каждая пара игроков встречается **ровно один раз**.

Формат каждого матча фиксированный — **FT2**.

FT в Round Robin не настраивается организатором.

### 5.1. Система очков

| Результат | Очки |
|---|---:|
| Победа 2:0 | 3 |
| Победа 2:1 | 2 |
| Поражение 1:2 | 1 |
| Поражение 0:2 | 0 |
| Техническая победа | 3 |
| Техническое поражение | 0 |

Техническая победа не считается результатом 2:0 для игровой статистики.

### 5.2. Tie-break

Если два или больше игроков заканчивают основной Round Robin с одинаковым количеством турнирных баллов, между ними проводится отдельный mini Round Robin.

Правила tie-break:

- участвуют только игроки с одинаковым количеством баллов;
- каждый играет с каждым один раз;
- все матчи играются FT2;
- места определяются по количеству побед в этой переигровке;
- результаты основной таблицы не пересчитываются;
- переигровка используется только для распределения итоговых мест.

Если после mini Round Robin часть игроков снова имеет одинаковое количество побед:

- переигрывает только оставшаяся равная группа;
- снова проводится mini Round Robin FT2;
- процесс повторяется до однозначного распределения мест.

### 5.3. Снятие игрока

Если игрок снимается с турнира после того, как уже сыграл часть матчей:

- все ранее сыгранные результаты сохраняются;
- ранее набранные очки сохраняются;
- оставшиеся матчи считаются техническими поражениями снятого игрока;
- его будущие соперники получают по 3 очка;
- снятый игрок получает 0 очков за эти матчи;
- прошлые результаты не аннулируются и не пересчитываются.

---

## 6. Forfeit — сдача матча

Forfeit означает, что игрок добровольно сдаёт **текущий матч**, но не обязательно покидает весь турнир.

Forfeit считается **техническим поражением**.

Правила:

- игровой счёт не подменяется искусственным результатом;
- матч помечается как техническое поражение;
- соперник автоматически считается победителем;
- сдавшийся игрок продолжает участие в турнире, если формат это позволяет.

Для DE:

- первое техническое поражение переводит игрока в Losers Bracket;
- второе техническое поражение выбивает игрока из турнира.

Для SE:

- техническое поражение означает вылет.

Для RR:

- победитель получает 3 очка;
- проигравший получает 0 очков;
- технический результат не считается 2:0 в игровой статистике.

---

## 7. Снятие игрока с турнира

Снятие игрока с турнира выполняет только организатор.

Игрок покидает турнир из своего текущего состояния.

При этом:

- уже сыгранные результаты не изменяются;
- уже зафиксированный счёт не изменяется;
- статистика прошлых матчей сохраняется;
- игрок больше не участвует в последующих матчах.

В DE и SE следующий соперник снятого игрока получает **техническую победу**.

В RR действуют специальные правила, описанные в разделе Round Robin.

Возврат снятого игрока обратно в турнир **не допускается**.

---

## 8. Исправление результата матча

Организатор может исправить результат матча, пока следующий зависимый матч ещё не сыгран.

После исправления:

- приложение автоматически пересчитывает затронутую часть сетки;
- корректный победитель переходит дальше;
- ещё не сыгранные зависимые матчи обновляются автоматически.

Если следующий зависимый матч уже сыгран, изменение предыдущего результата не допускается.

---

## 9. Отмена матча

Отдельный статус **Cancelled** на первом этапе не используется.

---

## 10. Ничья

Ничья на первом этапе не рассматривается и не поддерживается.

Каждый завершённый матч должен иметь одного победителя и одного проигравшего.

---

## 11. Итоговые продуктовые инварианты

1. Основной режим — Double Elimination.
2. Дополнительные режимы — Single Elimination и Round Robin.
3. Минимум участников — 2.
4. Начальная сетка DE/SE формируется случайно.
5. Bye распределяются случайно и не считаются победами.
6. Стандартный FT для DE/SE — FT1.
7. Финал DE/SE может иметь отдельную настройку FT.
8. Bracket Reset в DE используется всегда.
9. Bracket Reset использует FT Grand Final.
10. RR всегда играется FT2.
11. Каждая пара в RR играет ровно один матч.
12. В RR используется система очков 3/2/1/0.
13. При равенстве очков в RR проводится mini Round Robin FT2 до полного распределения мест.
14. Forfeit считается техническим поражением.
15. Снятие игрока не изменяет уже сыгранные результаты.
16. После старта новых участников добавлять нельзя.
17. Снятого игрока нельзя вернуть в турнир.
18. Результат можно исправить только пока следующий зависимый матч не сыгран.
19. После исправления приложение автоматически пересчитывает ещё не сыгранные зависимые матчи.
20. Для каждого режима формируется полный итоговый рейтинг участников.
21. Ничьи и отдельный статус Cancelled не входят в первый этап.
