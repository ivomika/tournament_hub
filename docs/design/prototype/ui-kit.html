SettingsDesktop native select; Mobile статичные значенияИсторическое расхождение. В UI kit Mobile-строка настроек открывает bottom sheet с вариантами, сохраняя исходное оформление; Desktop сохраняет поле выбора.
AchievementТёмная mobile-поверхность ↔ золотая desktop-плиткаЗафиксированный emphasis variant; не исправлен молча.
Identity fontflow-person использует разные font в distribution/competitionКонтекстные typography overrides. Кандидат на уточнение body/display роли; одинаковая анатомия.
Control surfacesDesktop FT canvas, Mobile FT raised; Input также меняет fillИсторические source-различия. TextField: единая surface-заливка. Stepper: единый Mobile-вид на обеих платформах; ошибочные Desktop overrides удалены.
SpacingDesktop20/12 встречаются систематически;28/9 и дробные значения локальны20/12 — плотность/композиция; остальные локальные либо clamp-результат. Не добавлены автоматически в глобальную шкалу.
Choice / modalВизуальная выборка selected и dialog не доказывает keyboard contractAT/keyboard semantics и modal focus ещё требуют production-реализации. Kit — визуальная библиотека.
Missing statesНет рабочего copied/loading-button/success/error-selection эталонаНе добавлены как обнаруженные состояния. Proposed примеры отдельно помечены. Test statuses не означают production-ready.
