# Динамический QR: контракт переноса

## Цель
Заменить готовую PNG-маску кодированием переданного текста, сохранив оформление UI kit: цвета основной темы, размер/радиус контейнера, padding, подпись, quiet zone4 модуля, соединённые округлённые модули и округлённые finder patterns. При другой ссылке стандартный QR-узор обязан изменяться; побитовое совпадение старой картинки не является критерием.

## План1 для задачи70
Стандартное кодирование выполняет изолированный pure-Dart QR adapter внутри визуального QR scope; собственная immutable AppQrMatrix не раскрывает библиотечные классы. Это visual encoding без I/O/инфраструктурных сервисов и без domain-сценария: ссылка уже передана компоненту. Никакой генерации LAN URL, сессий, сети или Clipboard. Допуск runtime encoder-пакета фиксируется при реализации; кандидат package:qr (https://pub.dev/packages/qr), стандарт QR versions1–40, ECC/UTF8. Готовый Flutter-renderer пакета не используется, чтобы сохранить исходную форму.

Независимый decoder zxing2 0.2.4 допущен только в dev_dependencies для roundtrip/scan тестов, без runtime импорта. Test-only API decoder из src ограничен одним owning тестом.

## Приёмка
Короткая/длинная/UTF8 ссылка декодируется в исходный текст независимым decoder; повторяемость и изменение входа; immutable матрица. После gate дополнительно декодируется реальный отрисованный PNG и проверяются mobile/desktop/theme/scaled goldens. Контрольные точки source comparison сохраняют геометрию/стиль; изменение encoded pattern явно документируется, не скрывается расширенным tolerance. Проверки нужны для QR, а не только для силуэта контейнера.

Runtime допуск: qr4.0.1 (BSD, pure Dart, pinned) используется только внутри app_qr_matrix_encoder.dart. Библиотека отвечает за version/ECC-M/masking/UTF8; не за Flutter-оформление. Painter использует module-grid data и finder geometry7/5/3 как QR artwork, а параметры закругления/quiet zone — через AppQrMetrics основной темы. Готовая PNG-маска больше не участвует в runtime.

Исходная сетка SVG33×33 определяет минимальную QR version4; длинные данные автоматически увеличивают version до допустимой40. Quiet zone4 и finder geometry сохраняют исходный масштаб для обычной ссылки. Модули заполняются одним составным Path, чтобы antialias не оставлял светлые швы между соседями.

UTF8: runtime явно добавляет ECI26. Независимый zxing2 извлекает верные byteSegments, но его Utf8Codec вызывается с signed Int8List и повреждает text для кириллицы; owning test нормализует уже декодированные byteSegments в Uint8List перед штатным utf8.decode. Никаких hints, подстановки payload или изменения QR parser не используется. Проверены реальные pixels, не только encoder matrix.

Максимум — вместимость QR version40/ECC-M; превышение отклоняется ArgumentError на границе adapter, без раскрытия library exception или содержимого ссылки. Виджет не обрезает данные молча.
