# Task

Используй [канонический workflow](../../../ai-context/workflow.md) в режиме **PLANNING_ONLY**. Прочитай AGENTS, context/rules и task-list/detail в установленном проектом порядке.

## Постановка

- Определи новую независимую цель либо уточнение существующей задачи. Номер, статус и Changelog веди по workflow и ai-context README.
- Исследуй существующие docs, code и tests; покажи понимание задачи и интерактивно выясни только unresolved решения.
- Сохраняй ответы и specification в карточке. Для цели с кодом карточка обязательна; для простой документации допускается только запись task-list по прежней механике.
- Используй существующий template: scope/non-goals, критерии, ошибки/границы, test scenarios и применимые leaf rules. Нерешённое поведение не заменяй предположением.
- Новая planning-only задача получает 🟣 и Stage DISCOVERY, затем SPEC_READY после согласованных ответов. Если пользователь отдельно просит implementation plan, сохрани его и Stage PLAN_READY; это не разрешает реализацию.

## Граница

Не пиши и не запускай RED tests, не меняй production-код и не переходи к IMPLEMENTING в этом skill. В постановке классифицируй TestGate по canonical workflow. Отдельный запрос реализации продолжает тот же номер; test-first и explicit approval нужны только для части с TestGate REQUIRED.

Результат: кратко сообщи номера/карточки, готовность постановки и нерешённые вопросы. Не дублируй полный процесс и не создавай второй реестр.
